# 이해 중심 집필과 설명의 깊이

## 목표와 범위

강의의 개념·논리·계산 과정을 해당 과목 수강생이 충분히 이해하고 스스로 적용하도록 설명한다. 성적 향상은 이해와 적용의 결과로 돕는다. 예상 시험 유형의 요령이나 암기 문장만 남기지 않는다. 동시에 원자료를 계기로 전문 이론·구현 내부·외부 지식을 계속 확장하지 않는다. 읽는 시간과 다른 과목의 학습 부담을 고려하되 고정 페이지 수나 글자 수를 맞추는 목표로 바꾸지 않는다.

**사용자가 지정한 독자 수준과 학습 방식을 집필·검토의 공통 기준으로 삼는다.** 과목명·학년이나 강의 중 ‘이미 배웠다’는 발언만으로 선수지식을 가정하지 않는다. 코딩 경험이 없는 독자라면 이번 코드·계산을 따라가는 데 필요한 변수·자료형·입력·반복·주소 등의 뜻을 해당 맥락에서 연결한다. 기존 설명을 정당화하려고 선수지식 목록을 사후에 높이지 않으며, 별도 선수 과목 전체를 새 단원으로 만들지도 않는다.

**원자료를 읽는 범위, 부수적 전문 확장의 범위, 남긴 설명의 완결성을 구별한다.** 지정 자료는 모두 읽고 강의의 주요 개념·논리·풀이를 파악한다. 본문에 남긴 개념·사례·코드는 등장 이유, 필요한 용어·관계, 결론까지의 중간 연결과 적용 조건을 독자가 따라갈 수 있어야 한다. 개념 이름·공식·경고·출처만으로 설명을 대신하지 않는다. 필요한 연결은 이번 강의의 이해 보조이며, 원자료에 등장한 모든 배경을 같은 깊이로 풀거나 외부 내용이라는 이유로 필수 연결을 금지하지 않는다.

| 내용의 역할 | 기본 처리 |
|---|---|
| 강의의 주요 개념·논리·계산·코드 흐름 | 본문에서 이해와 적용이 완결되게 설명. 결과나 공식만 남기지 않음 |
| 원자료의 부수적 전문 내용·배경·일화 | 현재 개념에서 맡는 역할과 필요한 결론까지 설명. 내부 이론의 상세 전개는 자동으로 추가하지 않음 |
| 외부 정의·중간 단계·정정 | 없을 때 생기는 구체적인 이해의 단절이나 오류를 해소하는 최소 범위만 본문에 추가 |
| 추가 전문 탐구·여러 일반화·구현별 예외 | 기본적으로 확장하지 않음. 명시적 요청이나 구체적인 학습 필요가 있을 때만 별도 선택 내용으로 다룸 |

난해한 용어나 추측한 학위 수준으로 필수 내용을 삭제하지 않는다. 실제 강의 목표·설명에서의 역할, 지정 독자의 선수지식, 교수의 강조·공식 과제와 평가 근거를 함께 본다. 강의가 직접 전개하거나 요구하는 어려운 개념·증명은 필요한 선수 연결을 보완해 설명한다. 단순 소개·참고와 구별하며, 실제 시험 근거가 없으면 출제를 예측해 범위를 줄이거나 ‘시험에 안 나옴’이라고 단정하지 않는다.

## 보충을 추가하고 멈추는 기준

보충 전에 **‘이 설명이 없으면 현재 강의의 무엇을 이해하거나 계산할 수 없는가?’**를 특정한다. 흥미롭다거나 관련 있다는 이유, 자체 제작 문항이 요구한다는 이유만으로는 부족하다. 짧은 정의·조건·중간 계산으로 연결되면 그 수준에서 멈춘다. 추가 설명을 이해하려고 별도 전문 이론을 다시 배워야 한다면, 먼저 그 확장이 현재 목표에 꼭 필요한지 재검토한다.

독자가 이유와 적용 조건을 말하고 대표 계산·코드 흐름을 새 값에 적용할 수 있으면, 같은 이유·방법의 증명·예제·그림을 자동으로 더하지 않는다. 같은 주제를 언급해도 정의·직관적 비유·사건 사례·적용 예시는 서로 다른 이해 기능을 가질 수 있다. 통합·제외할 때는 남은 본문의 어느 설명이 그 기능을 수행하는지 확인한다. 서로 다른 오류나 중요한 경우를 구별하는 예는 유지한다. 외부 출처는 필요한 사실을 확인하는 근거이지 주변 내용을 함께 수록해야 할 이유가 아니다. 검증 과정의 긴 설명은 제작 메모에 둔다.

필수 개념에 작은 선수 연결이 빠졌다면 본문에서 설명한다. 불필요한 확장을 위해 선수 내용을 연쇄 추가하지 않는다. 노트의 자립성은 이번 강의 이해에 필요한 연결을 갖춘다는 뜻이며 관련 분야 전체를 대체한다는 뜻이 아니다. 기록은 웹 SKILL.md의 기존 coverage 절차를 따르며 별도 점수표나 문단별 승인 절차는 만들지 않는다.

## 설명의 단위

강의자료와 병행하는 학습에서는 강의 PDF의 주요 질문과 전개 순서를 기본으로 삼고 전사 설명을 대응 위치에 통합한다. 정의를 먼저 두는 등 필요한 국소 재배치는 허용하되 도입 사례·비유를 뒤로 보내 정정만 앞에 남기지 않는다. 소절 또는 의미 단위에 정확한 원자료 쪽수를 표시하고, 서로 다른 구간을 넓은 범위 하나로 묶어 위치 안내를 대신하지 않는다. 슬라이드마다 절을 만들거나 모든 문장을 재수록할 필요는 없다.

페이지 제목 하나에 여러 역할이 들어갈 수 있다. 정의·이유·조건·계산·코드 흐름·사례·도표 해석이 서로 다른 질문에 답하면 계획에서 구별한다. 역할마다 기계적으로 별도 절을 만들라는 뜻은 아니다.

- **개념:** 용어의 일상적 뜻과 현재 문맥을 구별한다. 약어는 첫 등장에 풀고 이번 설명에 필요한 역할을 말한다. 예: ABI를 문제에서 요구하면 본문에서 먼저 뜻과 역할을 설명한다.
- **이유:** 조건→중간 이유→결론을 연결한다. ‘언제나 그런 것은 아니다’라는 문장은 원래 설계 동기의 대체물이 아니다.
- **계산:** 출발값·단위·중간 단계·결과·가정을 남긴다. 계산 방법을 처음 보여줄 때 역대입 검산만 쓰지 않는다.
- **코드:** 호출/입력→주요 식/반복→출력→그 결과가 뜻하는 것을 설명한다. 자료형 폭, 환경, 실행 여부를 필요한 위치에 붙인다. 원자료의 문제를 설명할 때 관련 입력·할당식·반복 조건·출력과 본문 설명을 대응시킨다. 필요하면 관련 줄만 발췌하고 오류와 수정 범위를 구별한다. 새 안전 코드·보충 함수가 원자료 분석을 대신하지 않게 하며 전체 프로그램 복원을 자동 요구하지 않는다.
- **사례:** 현재 개념을 설명하는 상황·비교·결론을 남긴다. 서로 다른 역할의 사례와 같은 결론의 반복을 구분하고, 부수적인 역사·제품 세부는 필요에 따라 축약한다. 오래됐다는 이유만으로 유용한 사례를 삭제하지 않는다.
- **시각자료:** 사진·수량 비유·값이 담긴 도식·참조표·코드 화면이 맡는 학습 기능을 구별한다. 원본 활용·목적을 밝힌 발췌·본문 설명으로 대체·재구성·제외를 그 기능에 따라 선택한다. ‘그림’, ‘농담’, ‘정의 반복’이라는 묶음 이름만으로 별도 기능을 지우지 않으며 모든 이미지의 수록을 의무화하지도 않는다. 학습에 필요한 값·관계와 이를 읽는 축·범례·주소 방향·단위·기호·주석을 보존한다. 큰 참조표는 대표값과 읽는 원리를 본문에 두고 실제 조회가 필요한 전체만 참조 영역에 둔다. 일부를 발췌하면 전체 표인 것처럼 표시하지 않고, 제외한 행에 별도 조건·경계·학습목표가 없는지 확인한다.

일반 강의 해설은 한 문단에 하나의 생각을 두고 요점에서 이유·조건으로 이어지는 쉬운 문장으로 쓴다. 나열·순서·비교가 실제로 읽기에 도움이 될 때 목록·표를 사용하며 모든 소절을 같은 박스나 문답 틀로 만들지 않는다. 학습에 필요한 계산·증명·코드 추적은 독자가 재현할 수 있는 풀이로 제시한다. 모델의 내부 사고 기록이나 작성 과정의 독백을 요구하는 뜻은 아니다. 모든 전사 해설에 태그를 붙이지 않는다. 실제 교수의 추가 사례만 ‘교수님 추가 설명’, 원자료에서 도출한 새 계산은 ‘노트 보충 풀이’, 원자료 밖의 사실은 ‘외부 보충’으로 구분한다.

## 이해하기 쉬운 설명인지 평가하고 고친다

사실이 맞는지와 독자가 이해할 수 있는지는 별도로 판단한다. 해당 과목의 수강생이 이 주차 내용을 처음 배우는 상황에서, 사용자 지정과 일치하는 선수지식 및 실제 제공된 선행 설명만으로 각 절과 문제 해설을 따라갈 수 있는지 읽는다. 검토자가 이미 아는 지식으로 생략된 연결을 머릿속에서 메우지 않는다.

- 새 용어·기호·변수는 사용 전에 뜻과 역할을 설명했는가? 지시어가 무엇을 가리키는가?
- ‘왜 그런가’와 ‘어떤 조건에서 성립하는가’가 연결되는가? 정의를 반복하거나 결론만 적어 이유를 대신하지 않았는가?
- 계산·알고리즘·코드는 입력에서 중간 상태를 거쳐 결과에 이르는 핵심 변화를 독자가 재현할 수 있는가? 식이나 추적표의 각 열·단계가 무엇을 뜻하는지 설명했는가?
- 예시·그림과 일반 원리를 연결했는가? 본문에서 배운 방법으로 문항을 풀 수 있고, 해설은 정답뿐 아니라 접근 이유와 과정을 설명하는가?

절마다 해당되는 질문을 판단하되 매 절에 같은 형식·예시·도식을 강요하지 않는다. 부족한 경우 ‘어렵다’라는 총평 대신 대상 구절, 독자가 답하지 못하는 질문 또는 빠진 연결을 특정한다. 필요한 용어·이유·중간 계산을 보완하고 수정된 문맥을 다시 읽는다. 반대로 목표와 연결되지 않는 전문 확장, 선수지식의 연쇄 추가, 동일 설명의 반복은 범위를 줄이거나 통합한다. 올바른 개념·조건과 이해에 필요한 깊이는 유지하되 기존 분량 자체를 보존 대상으로 삼지 않는다. 단순한 취향, 임의 점수, 페이지 증감을 개선 근거로 삼지 않는다.

## 문장·소제목·참조를 확인한다

학습노트와 문제집의 제목·소제목·본문·표의 제목과 머리글·그림 캡션·문항·해설을 처음부터 끝까지 읽는다. 오탈자, 비문, 중복·빠진 말, 용어·기호 불일치, 모호한 지시어를 확인한다. 계산이 맞는다는 이유로 문장 검토를 생략하지 않는다. 자동 검색·맞춤법 검사는 후보를 찾는 보조이며 전수 읽기를 대신하지 않는다.

‘위/아래 표’, ‘앞/뒤 그림’, 절·문항·페이지 번호는 실제 대상을 찾아 최종 PDF의 위치 및 번호와 대조한다. HTML 순서나 링크 목적지 존재만으로 방향 참조까지 맞다고 판단하지 않는다. 예를 들어 표가 문장 아래에 있는데 ‘위 추적표’라고 쓰면 계산과 별개의 참조 오류다. 이동이 잦거나 지시 대상이 모호하면 ‘추적표 2’처럼 명확한 이름으로 고치되 실제 제목·번호와 일치시킨다.

## 학습 본문과 제작 기록을 구별한다

- 필수 정의·판정 규칙·풀이 조건은 배우는 순서에 맞는 본문에서 설명한다. 정정 박스나 정답에서 규칙을 처음 가르치지 않는다. 조항 번호·링크는 근거일 뿐이므로 적용할 규칙과 현재 예제에서 조건을 어겼을 때의 결과는 문장으로 쓴다. 이와 무관한 표준·환경별 예외를 모두 펼치지는 않는다.
- 바른 개념·전형적인 사용 상황·현재 예제의 조건을 먼저 설명한 뒤 원자료와의 차이를 짧은 주석으로 연결한다. 예외·금지·일반화 제한은 이미 설명한 대상에 연결하며, 잘못된 주장을 처음 제시하고 ‘그대로 외우지 않는다’는 경고로 끝내지 않는다. 오답과 바른 조건을 나란히 보여야 혼동이 풀리는 경우만 짧은 정정 박스를 사용하고 본문 풀이를 반복하지 않는다. 주변 사실이나 강의 중 이미 바로잡힌 표현은 한 줄 주석 또는 제작 메모로 처리할 수 있다. 박스 개수·등급 점수는 요구하지 않는다.
- ‘원자료의 오류로 오해하지 않도록’, ‘보존한다’, ‘실행했다고 주장하는 것이 아니다’처럼 편집자에게 하는 말은 제작 메모로 옮긴다. 대신 학습에 필요한 값·조건·불확실성은 독자용 문장으로 남긴다. 실제 실행과 예상 출력의 구별, 잘못된 코드라는 표시는 의미를 바꾸므로 삭제하지 않는다.
- 전사 행 번호는 장별 원자료 안내·정정의 원문 위치·coverage.md에 두고 설명 문장에 반복하지 않는다. 자료 쪽수는 ‘강의 PDF p.N’ 또는 앞에서 정의한 파일 약칭과 함께 쓴다. 노트 자체의 절·쪽수와 구별한다.
- PDF와 함께 전달되지 않는 ZIP·coverage.md·실행 파일을 위치 없이 참조하지 않는다. 학습에 필수인 설명·코드·표는 PDF에서 찾을 수 있어야 한다. 편집본 안내가 필요하면 권말에 실제 접근 경로와 용도를 한 번 적는다.
- 바이트·주소·문자 코드의 진법을 문맥이나 접두사로 명확히 한다. 십진·16진 값이 함께 등장하는 예시는 0x 표기를 우선한다. 약어는 첫 등장에 해당 문맥의 뜻을 설명한다.

## 복습과 정보 보존

설명이 긴 노트에는 목차 뒤에 본문을 찾아가는 짧은 복습 길잡이를 둔다. 규칙과 필수 조건, 관련 절 링크를 함께 적고 새 사실·새 예제를 요약에서 처음 가르치지 않는다. 복습용임을 밝히고 아직 설명하지 않은 용어를 첫 읽기의 진입 조건으로 삼지 않는다. 고정된 ‘10줄’이나 한 페이지에 맞추려고 조건을 삭제하지 않는다.

전체 참조표·긴 원본의 반복 수록 여부는 실제 조회·학습 필요로 정한다. 필요한 경우 본문에 읽는 방법을 두고 전체를 권말에 둘 수 있으나, 본문에서 덜어낸 내용을 전부 부록에 옮겨 총부담을 유지하지 않는다. 원본 그림·재입력 표·출력이 같은 기능을 하면 하나로 통합한다. 원본 주석이 필요한 값을 가렸다면 원본을 변조하지 않고 해당 값만 텍스트로 보완한다.

확인 문제·연습문제의 소문항에는 식별 번호를 붙이고 해설도 같은 번호로 대응한다. 기본 문항 수를 자동으로 늘리지 않고 주요 목표는 기존 문항의 소문항·문제집과 함께 평가한다.

## 판서·시각 지시가 있는 전사

전사의 ‘여기’, ‘이쪽’, ‘필기’, ‘화살표’ 같은 표현과 생략된 식·그림을 주변 설명 및 강의 PDF와 대조한다. 이런 표현만으로 칠판 판서라고 단정하지 않는다. 현재 강의의 풀이·관계를 이해하는 데 필요한 구간을 다음 기준으로 처리한다. 필요한 재구성은 기본 집필에 포함하지만, 부수적인 전문 설명을 확장하거나 이미 충분한 해설에 예제를 더하는 이유로 삼지 않는다.

- **원자료 그림으로 설명이 완결되는 경우:** 해당 원본과 해설을 활용한다. 같은 정보를 새 판서 그림으로 중복 제작하지 않는다. 다만 교수의 설명이 원본과 다른 배치·방향·관점을 전제로 하면 그 관점을 실제로 보여 주는지 확인한다. 같은 값이 원본에 있다는 이유만으로 충분하다고 판단하지 않는다.
- **값·관계·풀이 과정이 충분한 경우:** 설명에 근거해 중간 단계를 포함한 학습용 도식을 재구성한다. 캡션은 **‘전사·강의자료 기반 재구성’**으로 표시하고 실제 근거 위치를 붙인다. 실제 필체·칠판 배치를 복원한 것처럼 말하지 않는다. 원자료에서 도출해 추가한 계산은 기존 ‘노트 보충 풀이’ 기준을 따른다.
- **설명하려는 개념은 명확하지만 판서의 값·배치가 불명확한 경우:** 같은 개념과 적용 조건을 보여 주는 새 값을 선택해 풀이·도식을 완성한다. **‘노트 보충 예시 — 원래 판서의 구체 값은 확인되지 않아 새 예시를 사용함’**처럼 출처와 새 예시를 구별한다. 선택한 값·폭·단위·가정을 명시하고 교수의 실제 예제로 귀속하지 않는다.
- **개념·조건 자체가 불명확하거나 충돌하는 경우:** 원문 의도를 임의 확정하지 않는다. 앞뒤 자료와 필요한 계산·일차 근거로 확인하고, 독립적으로 성립하는 보충 예시는 그 가정을 명시한다. 그것만으로 원래 설명을 복원했다고 하지 않으며 핵심 미해결점은 정정 기준에 따라 처리한다.

재구성·보충 예시는 관련 본문의 설명 및 중간 풀이와 연결해 **최종 PDF 안에** 넣는다. 원래 그림의 대체가 필요하지 않은 구간까지 그림 수를 늘리지 않는다. 수치·관계가 중요한 도식은 [디자인 기준](design.md)의 SVG·수식 조판을 우선한다.

원자료가 뒷받침하는 부분과 새로 만든 부분을 구별하고, 계산·비트·단위·화살표 방향·적용 조건 및 본문과 도식을 일치시킨다. 근거·가정·처리·위치·확인 결과의 기록은 웹 SKILL.md의 coverage 절차를 따른다.

## 정정 전에 원문을 판독한다

1. 앞뒤 문장과 PDF를 함께 읽고 누가 무엇을 주장했는지 확인한다.
2. 부정, 가정, 반문, 비교, 스스로 바로잡은 발언, 단위·소수점, 잘린 전사를 점검한다.
3. 실제 오류인지, 조건을 생략한 설명인지, 추출 손상인지 구별한다. 원문에서 올바르게 부정한 반례를 교수의 오류로 돌리지 않는다. 한 발언에 여러 주장이 묶여 있으면(예: ‘나누거나 곱하면 NaN’) 주장마다 따로 판정한다. 학습 결론에 영향을 주는 틀린 주장은 모두 바로잡고, 주변 사실은 아래 중요도 기준을 따른다.
4. 정정해도 현재 개념과 연결되는 사건 구조와 학습 취지는 남긴다. 사건 이름과 일반적인 경고만으로 사례 설명이 충분하다고 하지 않는다. 구조를 확인할 근거가 부족하면 확인 범위를 좁혀 밝히거나 해당 사례를 보류한다. 외부 확인은 필요한 사실·조건에 한정하고 주변 역사·전문 이론을 자동 확대하지 않는다.

정정에는 원문 위치·원자료 표현, 바르게 읽을 내용과 적용 조건, 실제 확인한 근거, 필요한 짧은 이유가 있어야 한다. 본문에는 짧은 출처명과 링크 또는 정확한 절을 두고 긴 URL·검토 이력은 권말/제작 메모로 보낸다. 번호만으로 출처의 정체를 숨기지 않는다.

### 중요도에 따라 확인 범위를 정한다

| 종류 | 필요한 처리 |
|---|---|
| 핵심 정의·계산·정답 영향 | 원자료와 계산/공식·일차 자료로 해결. 미해결이면 완성본으로 전달하지 않음 |
| 플랫폼·표준의 성립 조건 | 대상 환경을 명시. 현재 이해를 막는 일반화만 바로잡음 |
| 현재 가격·점유율·제품 구성 | 필요한 현재 사실이면 확인. 그렇지 않으면 당시 강의 사례임을 표시 |
| 역사·산업 사례·비유 | 학습 취지와 필요한 사건 구조 보존. 주변 세부의 확인을 끝없이 확대하지 않음 |
| 결말이 끊긴 전사 | 없는 발언을 복원하지 않음. 학습에 필수인 결론만 추가 확인 요청 |

외부 근거는 실제로 읽은 공식·일차 자료를 우선한다. 모델의 기억이나 Gemini 수집 메모만으로 ‘검증된 정정’이라고 하지 않는다. 원자료에서 직접 도출한 계산은 그 원자료와 계산 과정으로 충분하며, 형식상 URL을 만들 필요가 없다.

정정에도 앞의 ‘보충을 추가하고 멈추는 기준’을 적용한다. 간단한 조건·반례로 해결되면 후속 과목의 내부 구조를 새 단원으로 추가하지 않는다. 이미 밝힌 환경 가정·불확실성은 결론이 달라지는 지점에서만 다시 연결한다.

## 본문의 선택적 심화

- 원자료의 직접적인 학습 요구와 부수적인 전문 소개를 구분한다. 어려운 핵심을 선택으로 내려 암기 문장만 남기지 않고, 부수적인 전문 내용은 원자료에 있어도 상세 전개를 자동으로 의무화하지 않는다.
- 필요한 외부 정의·비유·중간 계산·정정은 본문에서 최소한으로 연결한다. 외부라는 이유로 모두 선택 읽기로 보내거나 금지하지 않는다.
- **심화 · 선택 읽기**는 추가 요청이나 구체적 필요가 있을 때만 둔다. 원자료 안의 부수적 탐구인지 외부 보충인지 출처를 그대로 구분한다. 전문 확장을 먼저 써 놓고 선택 태그만 붙이거나, 생략한 내용을 전부 권말에 모으지 않는다.
- 선택 소절을 건너뛰어도 본문과 기본 문항 및 제공한 강의 범위 응용 문항을 이해할 수 있어야 한다. 문항 의존성이 있으면 문항의 필요부터 재검토하며, 자체 제작 문제 때문에 전문 지식을 필수 본문으로 승격하지 않는다.

## 응용·심화 문제 · 강의 범위

이는 강의 PDF·전사본의 개념과 방법을 깊게 적용하는 문제이며, 본문의 선택적 심화 설명과 별개다. 선택 심화의 전문 지식을 선수지식으로 요구하지 않는다.

본문 확인 4개·문제집 기본 10개를 출발점으로 하되 사용자 지정과 주차 학습목표에 맞춘다. 기본 문제에도 이유 설명·새 값 적용·조건 판단을 포함하여 공식 대입 암기에 치우치지 않게 한다. 응용·심화 구역은 자동으로 추가하지 않는다. 강의 목표에 필요한 추가 적용을 기본 문항 교체·소문항으로 다루기 어렵거나 사용자가 요청한 경우에만 두며 고정 추가 개수는 없다.

개념 조합, 조건 판단, 오류 분석, 환경 비교, 여러 단계 추론으로 난도를 높인다. 단순 숫자 교체나 불필요한 큰 계산은 피한다. 필요한 폭·단위·주소 순서·환경·인코딩을 제공한다. 정보 부족을 묻는다면 가능한 해석과 필요한 추가 조건을 답할 수 있도록 명시한다.

정답은 권말에 실제 제공한 구역별로 배치하고 접근 순서·중간 과정·조건·흔한 오답 이유를 설명한다. 강의와 필요한 본문만으로 직접 풀어 확인한다. 자체 제작 문제집은 필수 범위를 정하는 독립 근거가 아니다. 부수적 전문 지식을 요구하는 문항은 먼저 범위를 줄이거나 교체하고, 공식 과제·평가가 실제 요구하는 내용과 구분한다. 출제 예측으로 표현하지 않는다.

## 문제와 정답의 타당성

핵심 학습목표를 확인 문제와 별도 문제집 전체에서 살핀다. 중요한 목표가 문항과 연결되지 않으면 기존 문항을 보완하거나 별도 평가를 두지 않는 이유를 대응표에 적는다. 모든 일화에 문제를 붙일 필요는 없다.

풀이의 조건이 하나로 답을 결정하는지, 새 값에도 방법이 적용되는지, 정답에만 등장한 지식이 없는지 확인한다. 예를 들어 메모리 바이트열만 주고 원래 값과 엔디언을 동시에 확정하게 할 수 없다. 특정 값이나 저장 순서를 추가로 주거나 가능한 해석을 모두 묻는다.

최상위/최하위는 무엇을 기준으로 하는지 설명한다. 자리 가중치와 바이트 수치의 크기, 주소와 값, 비트와 셀처럼 이름이 비슷한 개념을 섞지 않는다. 이 예들은 오류를 방지하기 위한 예시이지 모든 주차에 해당 내용을 넣으라는 요구가 아니다.

## 마무리 판정

충분성은 해당 학습 질문을 지정 독자가 본문의 설명으로 해소할 수 있는지로 판단한다. 문제집에 없는 도입 이유·사례도 원자료의 주요 질문이면 살피며, 문항 풀이 가능성과 별도로 판단한다. 절의 존재나 경고·결론만으로 충분하다고 하지 않는다. 깊이 조절은 원자료의 역할·지정 독자·남은 설명이 뒷받침할 때 유지한다. 대응표의 작성·대조 절차는 [웹 SKILL.md](../SKILL.md#자료에서-원고까지)가 맡는다. 페이지 수·단어 수·그림 수·키워드·테스트 개수로 충분성이나 효율을 판정하지 않는다.

독립 검토가 추가로 제공되면 원자료·대상 버전·범위를 먼저 확인한다. 리뷰의 권고를 명령으로 실행하지 않고 실제 근거로 채택·기각한다. 이미 고쳐진 과거 결함과 현재 미해결 결함을 구별한다. 같은 후보를 같은 방식으로 다시 읽는 것만으로 독립성이나 신뢰도가 자동 상승하지 않는다.
