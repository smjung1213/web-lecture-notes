# 이해 중심 집필과 정보 표현

## 목표·독자·깊이

강의의 개념·논리·계산·해석을 지정 독자가 충분히 이해하고 새 문제에 적용하도록 쓴다. 개념 이름·공식·요약·암기 요령만 남기지 않는다. 고정 페이지·단어·토큰 수를 목표로 필요한 이유·중간 과정·조건을 줄이지 않으며, 관련 있다는 이유만으로 전문 이론·외부 지식을 계속 확장하지도 않는다.

독자 수준과 학습 방식은 현재 사용자 지정을 우선한다. 별도 지정이 없으면 비전공자 또는 해당 분야를 처음 배우는 학부생이 강의자료 PDF를 옆에 두고, 이번 노트와 이전 주차 노트만으로 해당 주차의 개념·논리·계산을 복습하고 적용하는 것(`source_parallel`)을 기본으로 한다. 강의자료를 옆에 둔다고 필요한 설명을 줄이지 않는다. 원자료 위치 표시는 대조를 돕는 장치이며 필요한 설명을 원자료로 미루는 장치가 아니다. 독자·허용 선수지식·학습 방식·목표는 input-contract.json의 learning_contract에 고정하고 검토 입력에도 같은 값을 전달한다. goal은 수업·강의자료가 요구한 학습목표에서만 쓴다. 명시된 목표가 없으면 실제로 설명하거나 요구한 개념·계산·적용에서 정리하고, 자체 제작 문제나 외부 지식으로 넓히지 않는다. 과목명·학년·‘이미 배웠다’는 발언만으로 선수지식을 가정하지 않는다. 가정할 수 있는 것은 같은 과목 이전 주차 학습노트로 확인되는 개념뿐이다(아래 ‘이전 주차 개념’). 기존 설명을 정당화하려고 독자의 수준을 사후에 높이지 않는다. 작은 선수 연결이 필요하면 해당 개념을 이해하는 범위에서 설명한다. 관련 선수 과목 전체를 새 단원으로 만들지는 않는다.

원자료를 읽는 범위, 새 전문 확장의 범위, 남긴 설명의 완결성을 구별한다. 지정 자료는 모두 읽는다. 본문에 남긴 개념·코드·사례는 등장 이유, 용어·관계, 결론까지의 중간 연결, 적용 조건을 따라갈 수 있어야 한다. 강의가 직접 전개하거나 요구하는 어려운 개념·증명은 필요한 선수 연결과 함께 설명한다. 단순 소개·참고와 구별하고 근거 없이 ‘시험에 안 나옴’이라며 삭제하지 않는다.

| 내용의 역할·근거 | 깊이 선택 |
|---|---|
| 주요 개념·논리·유도·계산·코드·논증 | 지정 독자가 이해·재현·적용할 연결을 완결한다. |
| 근거: 수업에서 교수가 설명한 것 | 교수의 이유·예·일화·암기법·강조·수치까지 가장 자세히 설명한다. 규칙과 예를 함께 말했으면 둘 다 남긴다. 예만 남기면 새 경우에 적용하지 못한다. |
| 근거: 강의자료에만 있는 것(전사에 없거나 불완전) | 빼지 않는다. 자료가 보여 주는 내용을 이해할 수 있는 만큼 설명하고 외부로 넓히지 않는다. |
| 부수적 전문 배경·일화 | 현재 개념에서의 역할과 필요한 결론까지 설명하고 내부 이론의 상세 전개를 자동 추가하지 않는다. 수업에서 든 짧은 사례·일화는 학습 피로를 덜어 주므로 길게 늘이지 않는 범위에서 남긴다. |
| 근거: 외부 지식(외부 정의·중간 단계·정정) | 원자료 정정이나, 빠지면 생기는 구체적 단절·오류를 해소하는 범위만 추가한다. |
| 추가 탐구·여러 일반화·구현별 예외 | 명시적 요청이나 구체적인 학습 필요가 있을 때만 별도 선택 내용으로 다룬다. |

근거는 전사에 같은 용어가 있는지가 아니라 내용으로 판정한다. 음차(예: 커패시턴스)·영문·슬라이드 글자를 함께 본다. 전사에 없다는 이유만으로 강의자료 내용을 빼거나 외부 지식으로 보지 않는다. 수업·강의자료의 개념·조건을 풀어 쓰거나 그로부터 도출한 중간 단계·보충 예시는 외부 지식이 아니다(아래 ‘판서·시각 지시가 있는 전사’). 원자료에 없는 정의·법칙·적용 조건을 새로 들이면 외부 지식이다. 수업·자료가 유도 없이 주어진 사실로 쓴 공식·사실의 이면 원리는 새로 풀지 않는다. 이면 원리는 교수가 설명을 멈춘 곳에서 멈추되, 그 사실을 쓰는 데 필요한 기호·조건·대입·중간 계산은 줄이지 않는다. 이 깊이 제한과 아래 경계 문장 제한은 수업 밖의 원리·외부 확장에 적용한다. 교수가 수업에서 설명한 이유·예·일화·수치는 이 제한으로 줄이지 않는다.

새 전문 지식을 보충할 때는 현재 강의의 어떤 이해·적용을 돕는지 확인하고 그 목적과 무관한 확장을 멈춘다. 이 범위 제한을 기존 개념의 재설명·예시·그림을 줄이는 기준으로 쓰지 않는다. ‘일반화하지 않는다’ 같은 경계 문장은 독자가 실제로 잘못 일반화할 곳에만 쓴다. 교수 설명을 정정·경계 문장으로 바꾸지 않는다. 정정이 필요하면 교수 설명을 남기고 바로 뒤에서 원래 표현과 바른 내용을 밝힌다. 교수 설명에 근거가 있는 외부 사실은 본문에서 한두 문장으로 보충하고 출처를 밝힌다. 그보다 자세한 근거·구현 설명은 ‘원자료 바로잡기’ 블록 안에서 구체화한다. 교수의 회상이나 대략적 수치는 확실하지 않다는 이유로 빼지 않는다. ‘교수의 회상’, ‘수업에서 든 대략적 수치’처럼 출처와 성격을 밝혀 넣는다.

### 이전 주차 개념

사용자가 같은 과목 이전 주차 학습노트를 입력으로 주면 목차로 다룬 개념을 확인하고 필요한 절만 읽는다. 다룬 개념은 learning_contract의 prior_knowledge에 적는다(형식은 [learning-contract.md](learning-contract.md)). 이 개념은 정의·핵심 식 1–3줄과 출처(예: ‘1주차 2.2’)로 짧게 복습한다. 이번 주가 그 개념을 새로 쓰거나 넓힐 때만 자세히 설명한다. 이번 수업에서 교수가 다시 설명한 내용은 이전 주차 개념이어도 이번 주 내용이며 위 표의 ‘수업에서 교수가 설명한 것’으로 다룬다. 교수가 전제로만 쓴 개념만 짧은 복습과 참조로 한다. 이전 주차 노트로 확인할 수 없는 ‘배웠다’(다른 과목 등)와 1주차는 필요한 범위에서 설명한다.

### 현재 위치에서 이해를 돕는 반복

해당 부분을 이해하는 데 필요한 재설명·반복·예시를 충분히 제공한다. 앞에서 설명했거나 같은 결론이라는 이유로 생략하지 않는다. 동일한 정의·규칙도 새 예제의 출발점, 적용 조건의 확인, 풀이 이유, 현재 절만 읽을 때 필요한 연결이라면 다시 설명할 수 있다. 원리를 식·그림·구체적인 계산으로 거듭 확인하는 설명도 보존한다. 새 정보가 추가되지 않는다는 사실만으로 불필요한 반복이라고 판단하지 않는다.

삭제·통합은 현재 위치의 학습 역할을 확인하고, 필요한 연결을 유지하면서 실제 읽기 흐름이 좋아지는 경우에만 한다. 반복이라는 이유만으로 앞 절 참조로 대체하거나 짧은 문장으로 압축하지 않는다. 예외는 두 가지다. prior_knowledge에 적힌 이전 주차 개념은 위 ‘이전 주차 개념’대로 짧은 복습과 참조로 다룬다. 선행 개념이라 앞당겨 설명한 내용을 PDF의 원래 위치에서 다시 만나면 아래 ‘설명의 단위와 순서’대로 짧은 연결만 둔다. 학습 효과를 판단하기 어렵다면 설명을 유지한다. 분량·반복 횟수·모델 토큰 절약을 삭제 근거로 쓰지 않으며, 모든 설명을 무조건 복제하라는 뜻도 아니다.

## 보존과 표현 선택

원본 파일은 불변 보존한다. 결과 PDF에는 지정 독자가 필요한 사실·값·조건·관계·과정을 이해할 수 있게 남긴다. **그림의 위치·길이·방향·색 묶음·정렬·화살표로 직관적으로 이해하게 하는 방식 자체도 학습 정보다.** 같은 숫자·공식·문장을 옮겼다는 이유만으로 시각적 설명까지 보존했다고 판단하지 않는다.

수식은 MathJax로 조판하고, 이해를 돕는 원본 그림·도식·그래프는 필요한 영역을 추출·크롭해 본문에 유지하는 것을 기본으로 한다. 하나의 슬라이드에 수식·그림·표가 함께 있으면 역할을 나누어 판단한다. 수식을 재조판하거나 계산표를 옮긴 것으로 인접 도식의 보존을 대신하지 않는다. 수식의 논리와 그림의 직관은 서로 다른 기능이므로 같은 개념이라는 이유만으로 중복 제거하지 않는다.

| 역할 | 우선 표현과 선택 조건 |
|---|---|
| 정의·공식·유도·계산·본문 관계식 | 편집 가능한 LaTeX와 MathJax. 기호·조건·변형 이유·중간 과정을 연결한다. 함께 있는 도식은 별도로 보존한다. |
| 도식·그래프·지도·공간/단계/범위 비교 | 원본 추출·크롭을 우선한다. 위치·방향·길이·축·범례·색 묶음·연결 관계를 실제 PDF에서도 읽을 수 있게 한다. 표나 문장은 필요하면 설명을 보조하며 이 시각적 기능을 대체하지 않는다. |
| 데이터·비교·추적·분류 표 | 읽기 좋은 원본 표는 그대로 활용한다. 원본의 판독성·배치에 실제 문제가 있거나 정정·필요한 통합 등 구체적 이점이 있을 때만 재작성한다. |
| 사진·미술/문헌 이미지·실험 화면·실제 그림 | 원본을 활용하고 시각적 증거·라벨·주변 맥락을 유지한다. |
| 코드·출력 | 코드를 읽는 목적이면 문자·공백·들여쓰기를 보존한 정적 코드 블록을 쓴다. 화면 상태·필기·특정 줄을 가리키는 시각 설명도 학습에 필요하면 원본 영역과 함께 연결한다. |
| 인용·논증·설명 | 인용과 해석을 구별하고 주장·전제·근거·반론/제한·결론을 연결한다. 다른 과목에 표·수식 형식을 강제하지 않는다. |

**재작성·재구성의 예외:** 원본 영역·해상도·배치를 조정해도 필요한 라벨을 읽기 어렵거나, 확인된 오류의 정정·실질적으로 필요한 통합 등 원본 그대로는 해결되지 않는 이유가 있을 때 검토한다. 단순한 서식 통일, 편집 가능성, 이미지 작업 회피, 분량 절약만으로 유용한 원본을 바꾸지 않는다. 이유와 실제 개선을 기존 coverage에 짧게 적고, 새 표현에서도 원본의 시각적 설명 기능을 보존한다. 재구성 도식이 필요한 곳을 숫자 표로 바꾸지 않는다. 원본 접근이 막히면 해당 자료는 미확인으로 남기며 추측한 그림으로 원본을 확보했다고 하지 않는다.

**표를 재작성할 때:** 해당 범위의 행/열·머리글·값·부호·정밀도·단위·각주·빈 셀의 뜻·병합/그룹·순서·강조 관계와 읽는 법을 남긴다. 원본에서 한눈에 비교하던 표가 불필요하게 여러 쪽으로 갈라지거나 비트/값의 정렬이 무너지면 개선된 재작성으로 보지 않는다. 대표 몇 값이 같다고 전체 대응이라고 하지 않는다. 원자료에 표와 도식이 함께 있으면 표의 보존과 도식의 보존을 따로 확인한다.

**식 주변 표식:** 특정 항을 가리키는 짧은 기호 주석은 LaTeX 주석·인접 설명으로 명확히 옮길 수 있다. 그러나 여러 요소의 위치·구간·방향·단계 관계를 눈으로 따라가는 그림은 독립 시각자료다. 식 안의 설명이라는 이유로 그 그림까지 문장으로 치환하지 않는다.

원본 오류는 실제 페이지를 확인한 뒤 가까운 주석에 원자료 위치·원래 표현·올바른 내용·근거를 밝힌다. 텍스트 추출 오인식을 원본 오류로 단정하지 않는다. 도식을 고쳐야 해도 확인된 오류만 고치며 나머지 시각 관계를 보존한다. 판독 불가 부분은 불확실성으로 남기고 새 예를 원문 복원으로 제시하지 않는다.

같은 그림도 현재 설명과 함께 볼 필요가 있으면 다시 싣는다. 공통 위치로 통합해도 읽는 연결과 비교가 유지되는 경우에만 참조로 연결할 수 있다. 다만 서로 다른 조건·단계·대비 사례는 각각의 시각적 차이를 남긴다. 슬라이드 테마·무의미한 여백까지 반복할 필요는 없다. 원본 그림과 같은 개념의 계산·증명·읽는 법은 불필요한 중복이 아니다.

선택과 대응은 기존 inventory/coverage에 기록한다. 검토자는 원자료 시각자료와 최종 PDF의 대응 위치를 직접 비교한다. 그림 일부나 같은 숫자가 있다는 사실로 페이지 전체를 완전 대응 처리하지 않는다. 필요한 시각적 설명이 표·문장에만 흡수돼 사라졌으면 보존 결함이다. 편집 ZIP에만 있는 자산은 최종 PDF에서의 보존을 대신하지 않는다. 이미지 개수나 문장별 인증으로 자동 승인하지 않는다.

## 설명의 단위와 순서

절 순서는 강의자료 PDF의 쪽 순서를 기본으로 하고 전사 설명을 대응 위치에 통합한다. 한 절은 이어진 쪽 범위를 다룬다. 강의자료를 옆에 두고 읽는 독자가 PDF를 오가지 않게 하려는 것이다. 떨어진 쪽을 한 절에 모으거나 앞 쪽으로 되돌아가는 것은 뒤 내용에 꼭 필요한 선행 개념일 때만 하고, 그 자리에 짧게 안내한다. 순서를 벗어난 쪽에 그림·표·도식이 있으면 크롭을 넣는다. 글자 위주 쪽은 문장으로 옮겨도 된다. 앞당겨 설명한 내용을 PDF의 원래 위치에서 다시 만나면 짧은 연결만 두고 다시 설명하지 않는다(‘현재 위치에서 이해를 돕는 반복’의 예외). 그 위치에 새로 나온 예·조건·교수 설명은 그 자리에서 설명한다. 노트 흐름이 PDF와 똑같을 필요는 없다. 절 안에서 정의를 먼저 두는 등 국소 재배치는 가능하나 도입 사례·비유를 뒤로 보내 경고·정정만 남기지 않는다. 소절·의미 단위에 정확한 원자료 위치를 안내하고 서로 다른 구간을 큰 범위 하나로 덮지 않는다. 슬라이드마다 절을 만들거나 모든 문장을 전사할 필요는 없다.

개념은 새 용어·약어의 뜻과 현재 역할을 설명한다. 이유는 조건→중간 이유→결론으로 연결하며 ‘언제나 그런 것은 아니다’가 원래 이유의 대체물이 되지 않게 한다. 계산은 출발값·단위·중간 단계·결과·가정을 남긴다. 코드/절차는 입력→변화→출력→의미를 연결한다. 원자료 코드와 교정 코드, 예상 출력과 실제 실행 결과를 구별하고 관련 줄을 발췌할 때 분석에 필요한 조건·흐름을 남긴다. 인용·사례는 현재 개념을 설명하는 상황·전제·비교·결론을 유지한다. 역사적 사례를 오래됐다는 이유만으로 버리거나 주변 세부를 끝없이 확장하지 않는다.

문단은 하나의 중심 생각에서 이유·조건으로 이어진다. 나열·순서·비교에 실제 도움이 될 때 목록·표를 쓴다. 모든 절을 동일한 문답·박스로 만들지 않는다. 여기서 말하는 풀이 과정은 독자가 재현할 설명이며 모델의 내부 사고나 작성 독백이 아니다.

## 수식·유도·계산의 연결

공식이 있다는 것과 유도를 제공한다는 것은 다르다. 기호·범위·단위 → 출발식 → 대입·변형 이유 → 중간식 → 결과·조건에서 독자가 재현하지 못하는 연결을 채운다. 필요한 단계 수·문장 수·분량을 고정하지 않는다. 원자료의 유도를 말 설명만으로 대체하거나 재조판을 이유로 사실·계산 검증을 줄이지 않는다.

새 수학식은 단순 지수·첨자를 포함해 **MathJax가 처리하는 LaTeX**로 적는다. 인라인/독립 식, 시그마·분수·행렬·조건부 식·여러 줄 유도를 역할에 맞게 쓴다. 수동 `<sup>/<sub>`·유니코드 첨자·CSS 분수 조합을 새 수식의 조판 경로로 쓰지 않는다. 코드의 문법, 일반 문장 숫자, 화학식·각주처럼 비수학적 첨자는 해당 의미를 따른다. 기존 편집본의 옛 구조는 읽을 수 있게 유지하되 새로 고치는 수식은 LaTeX로 옮기고 영향 범위를 확인한다. 구문과 정적 변환은 design.md가 정한다.

기계적인 정적 변환 성공은 수학적 정확성의 증거가 아니다. 음수 부호와 연산자, 첨자 결합, 분수의 분자/분모 범위, 합의 시작/끝, 행렬의 행/열, 조건부 식의 경계, 등호/근사/함의 기호, 단위를 원자료·계산으로 검증한다. 수식 주석을 옮길 때 어느 항·변형을 설명하는지 확인한다.

## 출처·정정·불확실성의 자연스러운 표시

대부분의 설명은 평범한 본문으로 쓴다. 모든 문장 앞이나 중간에 출처 태그를 붙이지 않는다. 일반적으로 소절 제목 줄의 짧은 출처, 표/그림 캡션, 인용 출처, 관련 문장 뒤 주석이면 충분하다. 실제 교수의 추가 사례, 원자료에서 도출한 새 풀이, 외부 근거의 구별이 필요한 위치에서만 자연스러운 문장으로 밝힌다. 출처와 사실 확인 상태는 다른 정보이며 장식용 색상 태그로 섞지 않는다.

필수 정의·규칙은 배우는 순서의 본문에서 먼저 설명한다. 정정 설명이나 정답에서 처음 가르치지 않는다. 올바른 개념·조건·현재 예제를 설명한 뒤 원자료와의 차이를 짧게 연결한다. 오답과 바른 조건의 대비가 필요하면 정정 구역을 쓰며, 왜 틀렸는지 이해하는 데 필요한 규칙·풀이를 그 위치에서 다시 설명한다. 인용한 잘못된 원문만 페이지 끝에 남기지 않는다. 새 노트의 표현은 design.md에 따라 긴 정정은 F, 한 문장의 짧은 정정은 E(`[n]` 표시가 있는 페이지 하단 각주, 문서 전체 연속 번호)로 연결한다.

전사 행 번호는 제작 메모의 원자료 안내·정정 근거·coverage에 두고 본문에 넣지 않는다. PDF 쪽은 `05 p.3`처럼 원자료 범례의 라벨과 함께 쓰며(design.md ‘출처·주석·정정’) 노트 자체 쪽수와 구별한다. 긴 URL·실행·검토 이력, ‘원본을 보존한다’ 같은 편집자용 문장은 제작 메모로 옮긴다. 학습에 필요한 가정·값·실행 여부·불확실성은 본문에 남긴다. 동봉되지 않은 ZIP·스크립트를 위치 없이 참조하지 않는다.

## 판서·시각 지시가 있는 전사

전사의 ‘여기/이쪽/필기/화살표’를 주변 문장과 PDF에 대조한다. 그 말만으로 칠판 그림이 있다고 단정하지 않는다. 원자료 그림으로 설명이 완결되면 그대로 활용하고 같은 정보를 다시 그리지 않는다. 값·관계·풀이의 근거가 충분하면 ‘전사·강의자료 기반 재구성’과 정확한 근거 위치를 캡션에 둔다. 실제 필체·칠판 배치까지 복원했다고 하지 않는다.

개념은 분명하지만 판서의 값·배치가 불명확하면 필요한 경우 새 값·가정을 명시한 ‘노트 보충 예시’로 설명을 완성한다. 원래 구체 값을 확인하지 못했다는 사실을 구별하고 교수의 예제로 귀속하지 않는다. 개념·조건 자체가 충돌하면 원문 의도를 확정하지 말고 확인할 범위를 밝힌다. 독립적으로 성립하는 새 예시는 원문 복원의 증거가 아니다. 관련 그림·수식·풀이를 PDF 안에서 연결하고 기존 coverage에 근거·가정·처리·위치·결과를 남긴다.

## 정정의 판독과 확인 범위

앞뒤 문장·PDF와 함께 누가 무엇을 주장했는지 읽는다. 부정·가정·반문·비교·자기 정정·단위·소수점·잘린 전사를 점검한다. 실제 오류, 조건 생략, 추출 손상을 구별한다. 묶인 여러 주장도 각각 판정하며 원문에서 부정한 반례를 교수의 오류로 돌리지 않는다. 학습에 영향을 주는 틀린 주장과 주변 사실을 구분한다.

정정에는 원자료 위치와 표현, 올바른 내용과 조건, 실제 확인한 근거, 필요한 짧은 이유가 있어야 한다. 핵심 정의·계산·정답 영향은 원자료·계산/공식·일차 자료로 해결하며 미해결이면 완성 판정을 보류한다. 플랫폼/표준 조건은 필요한 환경을 명시하고 현재 오류를 바로잡는 범위로 확인한다. 가격·제품·역사 등의 주변 세부는 학습에 필요할 때만 확인하거나 당시 사례임을 밝힌다. 끊긴 전사에 없는 발언을 복원하지 않는다. 필요한 외부 근거는 실제 읽은 공식·일차 자료를 우선하며 모델 기억이나 수집 메모만으로 검증됐다고 하지 않는다. 원자료에서 직접 도출한 계산에 형식적인 URL을 만들 필요는 없다.

## 문제·복습·선택 읽기

확인 문제와 문제집은 주요 학습목표를 함께 다룬다. 모든 일화에 문항을 붙이거나 모든 주차에 같은 개수를 강제하지 않는다. 이유 설명·새 값/상황 적용·조건 판단·오류 분석으로 이해를 확인한다. 단순 숫자 교체와 불필요한 큰 계산만으로 난도를 올리지 않는다. 정답을 결정하는 값·단위·폭·환경·관점·자료 해석 조건을 제공한다. 정보 부족을 묻는다면 가능한 해석과 필요한 추가 조건을 답할 수 있게 한다.

문제에 필요한 개념·방법을 정답에서 처음 가르치지 않는다. 이번 노트와 이전 주차 노트만으로 직접 풀고 정답·조건·중간 단계·풀이의 일치를 확인한다. 역대입 검산만으로 최초 풀이 절차를 대신하지 않는다. 소문항과 해설 번호, 문제↔정답 링크를 맞춘다. 정답은 각 문서 권말의 실제 제공 구역에 둔다.

‘심화·선택 읽기’와 별도 ‘응용·심화 문제·강의 범위’는 필요하거나 요청된 경우에만 제공한다. 어려운 핵심을 선택으로 내려 암기 문장만 남기지 않는다. 필요한 외부 정의·중간 계산은 본문에 연결하고 무조건 선택으로 보내지 않는다. 기본/강의 범위 응용 문항은 선택 읽기에 의존하지 않는다. 자체 제작 문항은 필수 범위를 정하는 독립 근거가 아니며 부수 지식을 요구하면 문항을 먼저 교체·축소한다.

긴 노트는 본문으로 돌아가는 짧은 복습 길잡이를 둘 수 있다. 장 도입과 장 정리는 필요할 때만 쓰며 표현은 design.md를 따른다. 규칙·필수 조건·관련 절을 함께 두고 아직 설명하지 않은 새 사실을 요약에서 처음 가르치지 않는다. 복습을 위해 필요한 본문을 없애거나 고정 한 페이지·몇 줄에 맞추지 않는다.

## 학습 기능과 의미 대응

coverage의 ‘완전/충분’은 해당 원자료가 요구한 질문에 본문의 실제 설명으로 답할 수 있다는 근거에 연결한다. 계산 방법, 증명, 명칭의 이유, 적용 조건은 같은 구간에서도 별개 질문일 수 있다. 일부 기능을 보존하고 부수적 세부를 제외했다면 각각의 위치와 이유를 구별한다. 출처 번호·키워드·문항 수만 일치하는 것은 의미 대응 완료가 아니다.

이 기준은 웹의 coverage, 로컬 수정, 최종 PDF 확인에 같이 적용한다. 특정 사례의 문장 형식이나 상자 수를 모든 과목의 의무로 만들지 않는다.

## 충분성과 마무리 판정

노트와 문제집의 제목·본문·표·캡션·문항·해설을 처음부터 끝까지 읽는다. 새 용어·기호가 사용 전에 설명됐는지, 이유와 조건이 연결되는지, 계산/논증의 중간 과정이 재현되는지, 그림·사례와 일반 원리가 연결되는지 본다. **설명됨과 추론 가능함을 구별한다.** 충분 판정은 지정 독자가 현재 위치와 명시된 선수 연결만으로 원자료의 질문에 답하고 적용 조건·중간 이유를 설명할 수 있을 때 내린다. 검토자 지식으로 빠진 연결을 메워야 하면 추론 가능하나 설명 불충분이다. 같은 용어·공식·결론이나 관련 예제의 풀이 가능성만으로 관계 전체를 충분 처리하지 않는다. 부족하면 실제 구절·독자가 막히는 질문·필요한 보완을 특정한다. 문항에 없는 도입 이유·사례라도 주요 학습 질문이면 살핀다. 문제→노트의 풀이 의존성과 원자료 학습목표→노트·문제의 보존을 양쪽으로 확인한다. 자체 문제집과 본문이 같은 누락을 공유할 수 있으므로 문항을 모두 풀었다는 사실로 원자료 보존을 승인하지 않는다.

오탈자·비문·빠진 말·용어/기호 불일치·모호한 지시어와 실제 읽기 흐름을 방해하는 표현을 점검한다. 반복 설명은 위 학습 역할 기준으로 판단하며 독립적인 감축 목표로 삼지 않는다. ‘위/아래’, 절·문항·페이지 번호는 최종 PDF의 실제 대상과 대조한다. 자동 검색·맞춤법·링크 검사는 후보 탐지이며 전수 읽기의 대체물이 아니다.

충분성·표현 적절성·제안 채택·최종 가독성은 담당 모델이 근거로 판단한다. 페이지/그림/단어/테스트 개수, 소스 이미지 일치율, 원장 칸 채우기를 자동 승인 근거로 쓰지 않는다. 외부 검토는 현재 버전·범위를 확인한 뒤 채택·수정 후 채택·기각한다. 과거 결함과 현재 결함을 구별하며 새 근거 없이 같은 전체 검토를 반복하지 않는다. 실행과 기록은 SKILL.md·로컬 lecture-week가 맡는다.

### 교수 강조와 검토 뒤의 문장 정리

교수가 명시적으로 강조하거나 시험 가능성과 연결한 규칙·암기 요령·비유는 원문 취지대로 해당 설명에 표시한다. 새 노트에서는 해당 문장을 `.lec-wave`로 연결하며 모양은 design.md가 정한다. 부정확한 일반화에는 예제를 바르게 이해하는 조건을 붙여 살린다. 출제 가능성을 출제 보장으로 확대하거나 부정문으로 덮지 않는다. 요약·회상 질문은 필요한 곳에 두며 장마다 일정한 개수를 강제하지 않는다.

검토 대응으로 생긴 유보·편집자 문장은 문장별로 학습 기능을 판단한다. 필요한 가정·정정·새 예시 표시·원자료 귀속은 유지하고, 제작 경위만 설명하는 문장은 production-note.md에 기록한다. 소절의 출처 줄과 설명 도중의 잦은 행 번호를 구별한다. 필요한 설명과 근거를 개수 목표로 삭제하지 않는다.
