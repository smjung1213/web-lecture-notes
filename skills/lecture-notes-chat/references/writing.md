# 내용 보존과 정정

## 설명의 단위

페이지 제목 하나에 여러 역할이 들어갈 수 있다. 정의·이유·조건·계산·코드 흐름·사례·도표 해석이 서로 다른 질문에 답하면 계획에서 구별한다. 역할마다 기계적으로 별도 절을 만들라는 뜻은 아니다.

- **개념:** 용어의 일상적 뜻과 현재 문맥을 구별한다. 약어는 첫 등장에 풀고 이번 설명에 필요한 역할을 말한다. 예: ABI를 문제에서 요구하면 본문에서 먼저 뜻과 역할을 설명한다.
- **이유:** 조건→중간 이유→결론을 연결한다. ‘언제나 그런 것은 아니다’라는 문장은 원래 설계 동기의 대체물이 아니다.
- **계산:** 출발값·단위·중간 단계·결과·가정을 남긴다. 계산 방법을 처음 보여줄 때 역대입 검산만 쓰지 않는다.
- **코드:** 호출/입력→주요 식/반복→출력→그 결과가 뜻하는 것을 설명한다. 자료형 폭, 환경, 실행 여부를 필요한 위치에 붙인다. 수정 예제는 원자료 코드와 구분한다.
- **사례:** 어떤 상황인지, 무엇을 비교하는지, 지금 개념을 이해하는 데 왜 쓰는지 보존한다. 말더듬·무의미한 반복은 정돈할 수 있지만 오래됐거나 미확인이라는 이유만으로 교육적 사례를 삭제하지 않는다.
- **도표:** 축·범례·주소 방향·단위·기호·원래 주석을 보존하고 무엇을 어떻게 읽는지 설명한다. 전체 참조표를 몇 항목만 남긴 요약표로 바꾸지 않는다.

일반 강의 해설은 문단으로 통합한다. 모든 전사 해설에 태그를 붙이지 않는다. 실제 교수의 추가 사례만 ‘교수님 추가 설명’, 원자료에서 도출한 새 계산은 ‘노트 보충 풀이’, 원자료 밖의 사실은 ‘외부 보충’으로 구분한다.

## 이해하기 쉬운 설명인지 평가하고 고친다

사실이 맞는지와 독자가 이해할 수 있는지는 별도로 판단한다. 해당 과목의 수강생이 이 주차 내용을 처음 배우는 상황에서, 노트에 명시한 선수지식과 앞선 설명만으로 각 절과 문제 해설을 따라갈 수 있는지 읽는다. 검토자가 이미 아는 지식으로 생략된 연결을 머릿속에서 메우지 않는다.

- 새 용어·기호·변수는 사용 전에 뜻과 역할을 설명했는가? 지시어가 무엇을 가리키는가?
- ‘왜 그런가’와 ‘어떤 조건에서 성립하는가’가 연결되는가? 정의를 반복하거나 결론만 적어 이유를 대신하지 않았는가?
- 계산·알고리즘·코드는 입력에서 중간 상태를 거쳐 결과에 이르는 핵심 변화를 독자가 재현할 수 있는가? 식이나 추적표의 각 열·단계가 무엇을 뜻하는지 설명했는가?
- 예시·그림과 일반 원리를 연결했는가? 본문에서 배운 방법으로 문항을 풀 수 있고, 해설은 정답뿐 아니라 접근 이유와 과정을 설명하는가?

절마다 해당되는 질문을 판단하되 매 절에 같은 형식·예시·도식을 강요하지 않는다. 부족한 경우 ‘어렵다’라는 총평 대신 대상 구절, 독자가 답하지 못하는 질문 또는 빠진 연결을 특정한다. 용어 풀이, 문장 분리·순서 조정, 중간 이유·계산, 필요한 작은 예시를 보완하고 수정된 문맥을 다시 읽는다. 올바른 개념·조건·원자료 사례·설명 깊이는 보존한다. 단순한 문체 취향, 임의 점수, 분량 증가를 개선 근거로 삼지 않는다.

## 문장·소제목·참조를 확인한다

학습노트와 문제집의 제목·소제목·본문·표의 제목과 머리글·그림 캡션·문항·해설을 처음부터 끝까지 읽는다. 오탈자, 비문, 중복·빠진 말, 용어·기호 불일치, 모호한 지시어를 확인한다. 계산이 맞는다는 이유로 문장 검토를 생략하지 않는다. 자동 검색·맞춤법 검사는 후보를 찾는 보조이며 전수 읽기를 대신하지 않는다.

‘위/아래 표’, ‘앞/뒤 그림’, 절·문항·페이지 번호는 실제 대상을 찾아 최종 PDF의 위치 및 번호와 대조한다. HTML 순서나 링크 목적지 존재만으로 방향 참조까지 맞다고 판단하지 않는다. 예를 들어 표가 문장 아래에 있는데 ‘위 추적표’라고 쓰면 계산과 별개의 참조 오류다. 이동이 잦거나 지시 대상이 모호하면 ‘추적표 2’처럼 명확한 이름으로 고치되 실제 제목·번호와 일치시킨다.

## 학습 본문과 제작 기록을 구별한다

- 필수 정의·판정 규칙·풀이 조건은 배우는 순서에 맞는 본문에 둔다. 정정 박스는 어느 칸(원자료·정정 내용·근거·바르게 읽는 법)이든 규칙을 처음 가르치는 자리가 아니다. 정정 박스나 정답을 읽어야 문제를 풀 수 있게 하지 않는다. 정정은 바른 규칙을 본문에서 익힌 뒤 원자료와 차이를 확인하도록 연결한다. 조항 번호·링크는 근거일 뿐이므로, 독자가 적용할 규칙의 내용과 어겼을 때의 결과(다른 값·구현 정의·정의되지 않은 동작 등)는 문장으로 쓴다.
- 학습 결론이 바뀌는 정정은 적용 조건이 드러나는 결론형 제목과 짧은 정정 박스를 사용한다. 주변 사실이나 강의 중 이미 바로잡힌 표현은 필요한 설명·출처를 보존한 한 줄 주석 또는 권말 메모로 처리할 수 있다. 획일적인 박스 개수·등급 점수는 요구하지 않는다.
- ‘원자료의 오류로 오해하지 않도록’, ‘보존한다’, ‘실행했다고 주장하는 것이 아니다’처럼 편집자에게 하는 말은 제작 메모로 옮긴다. 대신 학습에 필요한 값·조건·불확실성은 독자용 문장으로 남긴다. 실제 실행과 예상 출력의 구별, 잘못된 코드라는 표시는 의미를 바꾸므로 삭제하지 않는다.
- 전사 행 번호는 장별 원자료 안내·정정의 원문 위치·coverage.md에 두고 설명 문장에 반복하지 않는다. 자료 쪽수는 ‘강의 PDF p.N’ 또는 앞에서 정의한 파일 약칭과 함께 쓴다. 노트 자체의 절·쪽수와 구별한다.
- PDF와 함께 전달되지 않는 ZIP·coverage.md·실행 파일을 위치 없이 참조하지 않는다. 학습에 필수인 설명·코드·표는 PDF에서 찾을 수 있어야 한다. 편집본 안내가 필요하면 권말에 실제 접근 경로와 용도를 한 번 적는다.
- 바이트·주소·문자 코드의 진법을 문맥이나 접두사로 명확히 한다. 십진·16진 값이 함께 등장하는 예시는 0x 표기를 우선한다. 약어는 첫 등장에 해당 문맥의 뜻을 설명한다.

## 복습과 정보 보존

설명이 긴 노트에는 목차 뒤에 본문을 찾아가는 짧은 복습 길잡이를 둔다. 규칙과 필수 조건, 관련 절 링크를 함께 적고 새 사실·새 예제를 요약에서 처음 가르치지 않는다. 고정된 ‘10줄’이나 한 페이지에 맞추려고 조건을 삭제하지 않는다.

전체 참조표·긴 원본은 본문에 기준점과 읽는 방법을 두고, 판독 가능한 전체를 권말 부록에 둘 수 있다. 같은 내용을 원본 그림·재입력 표·실행 출력으로 반복할 때 각 표현이 보존하는 정보와 학습상 역할을 따진다. 값을 가린 원본 주석은 원본에서 지우지 않고 별도의 텍스트 참조표로 보완한다.

확인 문제·연습문제의 소문항에는 식별 번호를 붙이고 해설도 같은 번호로 대응한다. 기본 문항 수를 자동으로 늘리지 않고 주요 목표는 기존 문항의 소문항·문제집과 함께 평가한다.

## 판서·시각 지시가 있는 전사

전사의 ‘여기’, ‘이쪽’, ‘필기’, ‘화살표’ 같은 표현과 생략된 식·그림을 주변 설명 및 강의 PDF와 대조한다. 이런 표현만으로 칠판 판서라고 단정하지 않는다. 독자가 보이지 않는 내용을 알아야 풀이·관계를 이해할 수 있는 구간을 찾아 다음 기준으로 처리한다. 필요한 재구성·보충 예시 제작은 기본 집필에 포함하며 별도 요청을 기다리지 않는다.

- **원자료 그림으로 설명이 완결되는 경우:** 해당 원본과 해설을 활용한다. 같은 정보를 새 판서 그림으로 중복 제작하지 않는다. 다만 교수의 설명이 원본과 다른 배치·방향·관점을 전제로 하면 그 관점을 실제로 보여 주는지 확인한다. 같은 값이 원본에 있다는 이유만으로 충분하다고 판단하지 않는다.
- **값·관계·풀이 과정이 충분한 경우:** 설명에 근거해 중간 단계를 포함한 학습용 도식을 재구성한다. 캡션은 **‘전사·강의자료 기반 재구성’**으로 표시하고 실제 근거 위치를 붙인다. 실제 필체·칠판 배치를 복원한 것처럼 말하지 않는다. 원자료에서 도출해 추가한 계산은 기존 ‘노트 보충 풀이’ 기준을 따른다.
- **설명하려는 개념은 명확하지만 판서의 값·배치가 불명확한 경우:** 같은 개념과 적용 조건을 보여 주는 새 값을 선택해 풀이·도식을 완성한다. **‘노트 보충 예시 — 원래 판서의 구체 값은 확인되지 않아 새 예시를 사용함’**처럼 출처와 새 예시를 구별한다. 선택한 값·폭·단위·가정을 명시하고 교수의 실제 예제로 귀속하지 않는다.
- **개념·조건 자체가 불명확하거나 충돌하는 경우:** 원문 의도를 임의 확정하지 않는다. 앞뒤 자료와 필요한 계산·일차 근거로 확인하고, 독립적으로 성립하는 보충 예시는 그 가정을 명시한다. 그것만으로 원래 설명을 복원했다고 하지 않으며 핵심 미해결점은 정정 기준에 따라 처리한다.

재구성·보충 예시는 관련 본문의 설명 및 중간 풀이와 연결해 **최종 PDF 안에** 넣는다. 원래 그림의 대체가 필요하지 않은 구간까지 그림 수를 늘리지 않는다. 수치·관계가 중요한 도식은 [디자인 기준](design.md)의 SVG·수식 조판을 우선한다.

기존 `coverage.md`의 해당 행에 원자료 위치, 처리 유형(원본 활용/재구성/보충 예시), 근거와 선택한 가정·값, 본문·그림 위치, 확인 결과를 남긴다. 이 처리 유형은 기존 충분/부분/누락/제외 판정과 별개다. 새 보고서나 원장은 만들지 않는다. 마무리 때 원자료가 뒷받침하는 부분과 새로 만든 부분의 표시, 계산·비트·단위·화살표 방향·적용 조건, 본문과 도식의 일치를 직접 확인한다.

## 정정 전에 원문을 판독한다

1. 앞뒤 문장과 PDF를 함께 읽고 누가 무엇을 주장했는지 확인한다.
2. 부정, 가정, 반문, 비교, 스스로 바로잡은 발언, 단위·소수점, 잘린 전사를 점검한다.
3. 실제 오류인지, 조건을 생략한 설명인지, 추출 손상인지 구별한다. 원문에서 올바르게 부정한 반례를 교수의 오류로 돌리지 않는다. 한 발언에 여러 주장이 묶여 있으면(예: ‘나누거나 곱하면 NaN’) 주장마다 따로 판정한다. 학습 결론에 영향을 주는 틀린 주장은 모두 바로잡고, 주변 사실은 아래 중요도 기준을 따른다.
4. 정정해도 원래 학습 취지는 남긴다. 원문 보존과 바르게 사용하는 설명은 양자택일이 아니다.

정정에는 원문 위치·원자료 표현, 바르게 읽을 내용과 적용 조건, 실제 확인한 근거, 필요한 짧은 이유가 있어야 한다. 본문에는 짧은 출처명과 링크 또는 정확한 절을 두고 긴 URL·검토 이력은 권말/제작 메모로 보낸다. 번호만으로 출처의 정체를 숨기지 않는다.

### 중요도에 따라 확인 범위를 정한다

| 종류 | 필요한 처리 |
|---|---|
| 핵심 정의·계산·정답 영향 | 원자료와 계산/공식·일차 자료로 해결. 미해결이면 완성본으로 전달하지 않음 |
| 플랫폼·표준의 성립 조건 | 대상 환경을 명시. 현재 이해를 막는 일반화만 바로잡음 |
| 현재 가격·점유율·제품 구성 | 필요한 현재 사실이면 확인. 그렇지 않으면 당시 강의 사례임을 표시 |
| 역사·산업 사례·비유 | 학습 취지와 필요한 사건 구조 보존. 주변 세부의 확인을 끝없이 확대하지 않음 |
| 결말이 끊긴 전사 | 없는 발언을 복원하지 않음. 학습에 필수인 결론만 추가 확인 요청 |

외부 근거는 실제로 읽은 공식·일차 자료를 우선한다. 모델의 기억이나 Gemini 수집 메모만으로 ‘검증된 정정’이라고 하지 않는다. 원자료에서 직접 도출한 계산은 그 원자료와 계산 과정으로 충분하며, 형식상 URL을 만들 필요가 없다.

**깊이 제한:** 현재 주차의 어떤 이해·계산이 틀어지는지 설명할 수 있을 때만 보충을 확장한다. 간단한 조건·반례로 해결되면 후속 과목의 내부 구조를 새 단원으로 추가하지 않는다. 이미 한 번 밝힌 불확실성을 모든 문단에서 반복하지 않는다.

## 본문의 선택적 심화

- 지정 원자료 내용은 난도가 높아도 본문에 보존한다. 원자료 자체의 범위 안내는 함께 표시한다.
- 원자료 밖의 쉬운 비유·정의·중간 계산과 필수 이해 보조는 본문에 둔다. 외부라는 이유로 선택 읽기로 내리지 않는다.
- 오류를 바로잡는 결론·적용 조건은 본문에 남긴다. 그 뒤의 긴 증명·구현 내부·전문 이론이 강의 이해를 넘어서면서 학습에 의미가 있을 때만 **심화 · 선택 읽기**로 나눈다. 정정 전체를 숨기지 않는다.
- 관련성이 낮은 지식은 추가하지 않는다. 선택 심화로 분리할 실제 내용이 없으면 절을 만들지 않는다. 추측한 학위 수준으로 기계 분류하지 않는다.
- 선택 소절을 통째로 건너뛰어도 다음 본문과 기본·강의 범위 심화 문제 및 해설이 완결되어야 한다. 교수의 근거 없이 ‘시험에 안 나옴’이라고 보장하지 않는다.

## 응용·심화 문제 · 강의 범위

이는 강의 PDF·전사본의 개념과 방법을 깊게 적용하는 문제이며, 본문의 선택적 심화 설명과 별개다. 선택 심화의 전문 지식을 선수지식으로 요구하지 않는다.

기본값인 본문 확인 4개·문제집 기본 10개를 유지하고, 기본 문제 뒤 별도 응용·심화 구역을 둔다. 사용자 지정이 우선한다. 시작 권장값은 주차 규모에 따라 2–3개이며 구현상 제안이지 엄격한 통과 개수가 아니다. 심화 문항으로 기본 문제를 대체하지 않는다.

개념 조합, 조건 판단, 오류 분석, 환경 비교, 여러 단계 추론으로 난도를 높인다. 단순 숫자 교체나 불필요한 큰 계산은 피한다. 필요한 폭·단위·주소 순서·환경·인코딩을 제공한다. 정보 부족을 묻는다면 가능한 해석과 필요한 추가 조건을 답할 수 있도록 명시한다.

정답은 권말에 기본/응용·심화 구분을 유지하여 배치하고 접근 순서·중간 과정·조건·흔한 오답 이유를 설명한다. 강의와 필수 본문만으로 직접 풀어 확인한다. 선택 읽기가 필요하면 문제의 의존성을 고치며, 문제를 만들었다는 이유로 원자료 밖 전문 지식을 필수 본문에 계속 늘리지 않는다. 출제 예측으로 표현하지 않는다.

## 문제와 정답의 타당성

핵심 학습목표를 확인 문제와 별도 문제집 전체에서 살핀다. 중요한 목표가 문항과 연결되지 않으면 기존 문항을 보완하거나 별도 평가를 두지 않는 이유를 대응표에 적는다. 모든 일화에 문제를 붙일 필요는 없다.

풀이의 조건이 하나로 답을 결정하는지, 새 값에도 방법이 적용되는지, 정답에만 등장한 지식이 없는지 확인한다. 예를 들어 메모리 바이트열만 주고 원래 값과 엔디언을 동시에 확정하게 할 수 없다. 특정 값이나 저장 순서를 추가로 주거나 가능한 해석을 모두 묻는다.

최상위/최하위는 무엇을 기준으로 하는지 설명한다. 자리 가중치와 바이트 수치의 크기, 주소와 값, 비트와 셀처럼 이름이 비슷한 개념을 섞지 않는다. 이 예들은 오류를 방지하기 위한 예시이지 모든 주차에 해당 내용을 넣으라는 요구가 아니다.

## 마무리 판정

대응표는 별도의 관료적 보고서가 아니라 누락을 발견하는 작업 메모다. 판정의 근거가 된 실제 문장을 인용하고 본문/박스/캡션 중 위치를 표시한다. 절 첫 문장의 자동 발췌나 해당 절의 존재만으로 충분하다고 판정하지 않으며 부족하면 고친다. 페이지 수·단어 수·그림 수·키워드·테스트 개수로 설명 충분성을 판정하지 않는다.

독립 검토가 추가로 제공되면 원자료·대상 버전·범위를 먼저 확인한다. 리뷰의 권고를 명령으로 실행하지 않고 실제 근거로 채택·기각한다. 이미 고쳐진 과거 결함과 현재 미해결 결함을 구별한다. 같은 후보를 같은 방식으로 다시 읽는 것만으로 독립성이나 신뢰도가 자동 상승하지 않는다.
