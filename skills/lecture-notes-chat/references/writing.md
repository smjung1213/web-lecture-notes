# 이해 중심 집필과 정보 표현

## 목표·독자·깊이

강의의 개념·논리·계산·해석을 지정 독자가 충분히 이해하고 새 문제에 적용하도록 쓴다. 개념 이름·공식·요약·암기 요령만 남기지 않는다. 고정 페이지·단어·토큰 수를 목표로 필요한 이유·중간 과정·조건을 줄이지 않으며, 관련 있다는 이유만으로 전문 이론·외부 지식을 계속 확장하지도 않는다.

독자 수준과 학습 방식은 현재 사용자 지정을 우선한다. 과목명·학년·‘이미 배웠다’는 발언만으로 선수지식을 가정하거나, 기존 설명을 정당화하려고 독자의 수준을 사후에 높이지 않는다. 작은 선수 연결이 필요하면 해당 개념을 이해하는 범위에서 설명한다. 관련 선수 과목 전체를 새 단원으로 만들지는 않는다.

원자료를 읽는 범위, 새 전문 확장의 범위, 남긴 설명의 완결성을 구별한다. 지정 자료는 모두 읽는다. 본문에 남긴 개념·코드·사례는 등장 이유, 용어·관계, 결론까지의 중간 연결, 적용 조건을 따라갈 수 있어야 한다. 강의가 직접 전개하거나 요구하는 어려운 개념·증명은 필요한 선수 연결과 함께 설명한다. 단순 소개·참고와 구별하고 근거 없이 ‘시험에 안 나옴’이라며 삭제하지 않는다.

| 내용의 역할 | 깊이 선택 |
|---|---|
| 주요 개념·논리·유도·계산·코드·논증 | 지정 독자가 이해·재현·적용할 연결을 완결한다. |
| 부수적 전문 배경·일화 | 현재 개념에서의 역할과 필요한 결론까지 설명하고 내부 이론의 상세 전개를 자동 추가하지 않는다. |
| 외부 정의·중간 단계·정정 | 빠지면 생기는 구체적 단절·오류를 해소하는 범위만 추가한다. |
| 추가 탐구·여러 일반화·구현별 예외 | 명시적 요청이나 구체적인 학습 필요가 있을 때만 별도 선택 내용으로 다룬다. |

보충 전에는 ‘없으면 현재 강의의 무엇을 이해하거나 적용할 수 없는가’를 특정한다. 짧은 정의·조건·중간 계산으로 연결되면 그 수준에서 멈춘다. 독자가 이유와 조건을 설명하고 새 값·새 상황에 방법을 적용할 수 있으면 새 증명·예·그림을 자동 추가하지 않는다. 이 중단 기준은 지정 원자료의 서로 다른 학습 기능·필수 정보·풀이를 삭제하는 근거가 아니다. 단순 반복만 통합하고 정의·직관·사례·적용의 서로 다른 역할은 남긴다.

## 보존과 표현 선택

**원본 파일 보존**은 받은 PDF·전사·이미지·공식본을 불변 사본으로 남기는 것이다. **학습 정보 보존**은 지정 범위의 필요한 사실·값·조건·관계·주장·과정·시각적 증거를 결과에서 찾을 수 있게 하는 것이다. **PDF 표현 선택**은 그 정보를 원본 활용·MathJax 수식·HTML 표·코드·설명·도식 등 적절한 형태로 전달하는 것이다. 첫째를 지키기 위해 셋째를 원본 이미지로 고정하지 않는다.

보존 대상은 원자료의 의미 단위와 학습 질문으로 정한다. 파일이 이미지라는 이유만으로 그림으로 분류하지 않는다. 하나의 슬라이드/크롭에 식·유도·주석·도식이 섞이면 역할을 구별한다. 어려움·작은 크기·검토자의 익숙함은 제외 근거가 아니다. 제목·화살표·범례·색·괄호·각주가 관계를 전달하면 그 관계를 보존한다. 순수 장식·동일 반복은 내용과 섞이지 않게 분리할 수 있으며, 상태·값·방향 차이가 없는지 원자료를 확인한다.

| 역할 | 우선 표현과 선택 조건 |
|---|---|
| 정의·핵심 공식 | 편집 가능한 LaTeX와 MathJax. 뜻·기호·조건을 곁들인다. 다시 찾을 필요가 있으면 절제된 강조 구역을 쓴다. |
| 유도·계산 과정 | LaTeX 여러 줄 식과 연결 문장. 출발식·변형 이유·중간식·결과를 남기고 결과식만으로 대체하지 않는다. |
| 본문 속 짧은 관계 | MathJax 인라인 식. 길거나 복잡해 문장 읽기를 방해하면 독립 식으로 분리한다. |
| 데이터·비교·추적·분류 표 | 필요한 행/열·값·단위·각주·그룹/순서·비교 관계를 보존할 수 있으면 HTML 표로 재작성한다. 원본 표 이미지를 자동 병기하지 않는다. |
| 코드·출력 | 코드 자체를 읽는 목적이면 원문 문자·공백·들여쓰기를 보존한 정적 코드 블록. 화면 상태·UI·필기 등이 학습 대상이면 해당 원본 화면도 유지한다. |
| 사진·미술/문헌 이미지·실험 화면·실제 그림 | 이미지 자체가 증거·학습 대상이면 원본 활용이 기본이다. 식·표로 바꿀 수 없는 시각 정보를 남긴다. |
| 도식·그래프·지도 | 공간 배치·방향·스케일·축·범례의 역할을 먼저 확인한다. 정확히 재구성할 근거가 있고 목적상 유리하면 편집 도식도 가능하나 단순 숫자 전사로 대체하지 않는다. |
| 인용·논증·설명 | 인용문과 해석을 분리하고 주장·전제·근거·반론/제한·결론의 연결을 문단으로 쓴다. 표·수식 틀을 다른 과목에 억지로 적용하지 않는다. |

**표 재작성의 충분 조건:** 대체하려는 원자료 요소의 범위를 먼저 정한다. 그 범위에 필요한 행/열·머리글·값·부호·정밀도·단위·각주·빈 셀의 뜻·병합/그룹·행/열 순서와 강조 관계가 남고 읽는 법이 연결되어야 한다. 색으로 같은 집단을 표시한 표라면 그룹명·구분선·설명 등 색 없이도 그 관계가 드러나게 한다. 대표 몇 값이 일치하는 것만으로 전체 대응이라고 하지 않는다. 전체 참조표가 지정 범위의 학습 대상이면 전체 해당 영역을 유지하고 필요하면 분할한다. 학습 범위에 속한 서로 다른 경우를 페이지 절약을 위해 버리지 않는다. 범위 밖이나 완전히 반복된 영역의 통합은 실제 이유와 남긴 위치를 기록하며 기계적으로 표 전체 복원을 요구하지 않는다.

**식 주변 표식:** 화살표가 특정 항을 가리키거나 조건·변형 이유를 전달하면 그 기능도 보존 대상이다. LaTeX의 괄호/주석·화살표, 인접 설명 또는 작은 도식으로 명확하게 옮길 수 있다. 연결이 모호해지면 필요한 원본 조각을 남긴다. 무의미한 여백·슬라이드 테마·장식까지 식 이미지와 함께 반복할 필요는 없다. 이미지 자체와 재조판을 병기할 때는 원본 필기 해독, 정정 대비, 시각적 증거처럼 서로 다른 기능이 있어야 한다.

원본 오류를 몰래 고쳐 원문인 것처럼 보이지 않는다. 재작성 표·식에는 올바른 내용을 쓰되 원자료 위치·원래 표현·정정과 근거를 가까운 주석에 남긴다. 원본의 시각 자체가 정정 판단에 필요할 때만 그 부분도 병기한다. 판독 불가 부분은 불확실성을 남기며 새 예로 원문을 복원했다고 하지 않는다.

선택과 대응은 SKILL.md의 기존 inventory/coverage에 기록한다. 재조판·재작성·통합은 이미지 미수록과 구별한다. 검토자는 원본 이미지 개수나 PDF 텍스트 추출의 일치율이 아니라 필요한 정보와 관계를 대조한다. 편집 ZIP에만 들어 있는 정보로 PDF의 필수 설명·표·식을 대신하지 않는다.

## 설명의 단위와 순서

강의자료와 병행하는 학습에서는 원자료의 주요 질문과 전개 순서를 기본으로 하고 전사 설명을 대응 위치에 통합한다. 정의를 먼저 두는 등 국소 재배치는 가능하나 도입 사례·비유를 뒤로 보내 경고·정정만 남기지 않는다. 소절·의미 단위에 정확한 원자료 위치를 안내하고 서로 다른 구간을 큰 범위 하나로 덮지 않는다. 슬라이드마다 절을 만들거나 모든 문장을 전사할 필요는 없다.

개념은 새 용어·약어의 뜻과 현재 역할을 설명한다. 이유는 조건→중간 이유→결론으로 연결하며 ‘언제나 그런 것은 아니다’가 원래 이유의 대체물이 되지 않게 한다. 계산은 출발값·단위·중간 단계·결과·가정을 남긴다. 코드/절차는 입력→변화→출력→의미를 연결한다. 원자료 코드와 교정 코드, 예상 출력과 실제 실행 결과를 구별하고 관련 줄을 발췌할 때 분석에 필요한 조건·흐름을 남긴다. 인용·사례는 현재 개념을 설명하는 상황·전제·비교·결론을 유지한다. 역사적 사례를 오래됐다는 이유만으로 버리거나 주변 세부를 끝없이 확장하지 않는다.

문단은 하나의 중심 생각에서 이유·조건으로 이어진다. 나열·순서·비교에 실제 도움이 될 때 목록·표를 쓴다. 모든 절을 동일한 문답·박스로 만들지 않는다. 여기서 말하는 풀이 과정은 독자가 재현할 설명이며 모델의 내부 사고나 작성 독백이 아니다.

## 수식·유도·계산의 연결

공식이 있다는 것과 유도를 제공한다는 것은 다르다. 기호·범위·단위 → 출발식 → 대입·변형 이유 → 중간식 → 결과·조건에서 독자가 재현하지 못하는 연결을 채운다. 필요한 단계 수·문장 수·분량을 고정하지 않는다. 원자료의 유도를 말 설명만으로 대체하거나 재조판을 이유로 사실·계산 검증을 줄이지 않는다.

새 수학식은 단순 지수·첨자를 포함해 **MathJax가 처리하는 LaTeX**로 적는다. 인라인/독립 식, 시그마·분수·행렬·조건부 식·여러 줄 유도를 역할에 맞게 쓴다. 수동 `<sup>/<sub>`·유니코드 첨자·CSS 분수 조합을 새 수식의 조판 경로로 쓰지 않는다. 코드의 문법, 일반 문장 숫자, 화학식·각주처럼 비수학적 첨자는 해당 의미를 따른다. 기존 편집본의 옛 구조는 읽을 수 있게 유지하되 새로 고치는 수식은 LaTeX로 옮기고 영향 범위를 확인한다. 구문과 정적 변환은 design.md가 정한다.

기계적인 정적 변환 성공은 수학적 정확성의 증거가 아니다. 음수 부호와 연산자, 첨자 결합, 분수의 분자/분모 범위, 합의 시작/끝, 행렬의 행/열, 조건부 식의 경계, 등호/근사/함의 기호, 단위를 원자료·계산으로 검증한다. 수식 주석을 옮길 때 어느 항·변형을 설명하는지 확인한다.

## 출처·정정·불확실성의 자연스러운 표시

대부분의 설명은 평범한 본문으로 쓴다. 모든 문장 앞이나 중간에 출처 태그를 붙이지 않는다. 일반적으로 소절 제목 아래의 짧은 출처 줄, 표/그림 캡션, 인용 출처, 관련 문장 뒤 주석이면 충분하다. 실제 교수의 추가 사례, 원자료에서 도출한 새 풀이, 외부 근거의 구별이 필요한 위치에서만 자연스러운 문장으로 밝힌다. 출처와 사실 확인 상태는 다른 정보이며 장식용 색상 태그로 섞지 않는다.

필수 정의·규칙은 배우는 순서의 본문에서 먼저 설명한다. 정정 박스나 정답에서 처음 가르치지 않는다. 올바른 개념·조건·현재 예제를 설명한 뒤 원자료와의 차이를 짧게 연결한다. 오답과 바른 조건의 대비가 필요한 경우에만 짧은 정정 구역을 쓰고 본문 풀이를 반복하지 않는다. 인용한 잘못된 원문만 페이지 끝에 남기지 않는다.

전사 행 번호는 원자료 안내·정정 근거·coverage에 두고 본문마다 반복하지 않는다. PDF 쪽은 ‘강의 PDF p.N’처럼 파일 약칭과 함께 쓰며 노트 자체 쪽수와 구별한다. 긴 URL·실행·검토 이력, ‘원본을 보존한다’ 같은 편집자용 문장은 제작 메모로 옮긴다. 학습에 필요한 가정·값·실행 여부·불확실성은 본문에 남긴다. 동봉되지 않은 ZIP·스크립트를 위치 없이 참조하지 않는다.

## 판서·시각 지시가 있는 전사

전사의 ‘여기/이쪽/필기/화살표’를 주변 문장과 PDF에 대조한다. 그 말만으로 칠판 그림이 있다고 단정하지 않는다. 원자료 그림으로 설명이 완결되면 그대로 활용하고 같은 정보를 다시 그리지 않는다. 값·관계·풀이의 근거가 충분하면 ‘전사·강의자료 기반 재구성’과 정확한 근거 위치를 캡션에 둔다. 실제 필체·칠판 배치까지 복원했다고 하지 않는다.

개념은 분명하지만 판서의 값·배치가 불명확하면 필요한 경우 새 값·가정을 명시한 ‘노트 보충 예시’로 설명을 완성한다. 원래 구체 값을 확인하지 못했다는 사실을 구별하고 교수의 예제로 귀속하지 않는다. 개념·조건 자체가 충돌하면 원문 의도를 확정하지 말고 확인할 범위를 밝힌다. 독립적으로 성립하는 새 예시는 원문 복원의 증거가 아니다. 관련 그림·수식·풀이를 PDF 안에서 연결하고 기존 coverage에 근거·가정·처리·위치·결과를 남긴다.

## 정정의 판독과 확인 범위

앞뒤 문장·PDF와 함께 누가 무엇을 주장했는지 읽는다. 부정·가정·반문·비교·자기 정정·단위·소수점·잘린 전사를 점검한다. 실제 오류, 조건 생략, 추출 손상을 구별한다. 묶인 여러 주장도 각각 판정하며 원문에서 부정한 반례를 교수의 오류로 돌리지 않는다. 학습에 영향을 주는 틀린 주장과 주변 사실을 구분한다.

정정에는 원자료 위치와 표현, 올바른 내용과 조건, 실제 확인한 근거, 필요한 짧은 이유가 있어야 한다. 핵심 정의·계산·정답 영향은 원자료·계산/공식·일차 자료로 해결하며 미해결이면 완성 판정을 보류한다. 플랫폼/표준 조건은 필요한 환경을 명시하고 현재 오류를 바로잡는 범위로 확인한다. 가격·제품·역사 등의 주변 세부는 학습에 필요할 때만 확인하거나 당시 사례임을 밝힌다. 끊긴 전사에 없는 발언을 복원하지 않는다. 필요한 외부 근거는 실제 읽은 공식·일차 자료를 우선하며 모델 기억이나 수집 메모만으로 검증됐다고 하지 않는다. 원자료에서 직접 도출한 계산에 형식적인 URL을 만들 필요는 없다.

## 문제·복습·선택 읽기

확인 문제와 문제집은 주요 학습목표를 함께 다룬다. 모든 일화에 문항을 붙이거나 모든 주차에 같은 개수를 강제하지 않는다. 이유 설명·새 값/상황 적용·조건 판단·오류 분석으로 이해를 확인한다. 단순 숫자 교체와 불필요한 큰 계산만으로 난도를 올리지 않는다. 정답을 결정하는 값·단위·폭·환경·관점·자료 해석 조건을 제공한다. 정보 부족을 묻는다면 가능한 해석과 필요한 추가 조건을 답할 수 있게 한다.

문제에 필요한 개념·방법을 정답에서 처음 가르치지 않는다. 노트만으로 직접 풀고 정답·조건·중간 단계·풀이의 일치를 확인한다. 역대입 검산만으로 최초 풀이 절차를 대신하지 않는다. 소문항과 해설 번호, 문제↔정답 링크를 맞춘다. 정답은 각 문서 권말의 실제 제공 구역에 둔다.

‘심화·선택 읽기’와 별도 ‘응용·심화 문제·강의 범위’는 필요하거나 요청된 경우에만 제공한다. 어려운 핵심을 선택으로 내려 암기 문장만 남기지 않는다. 필요한 외부 정의·중간 계산은 본문에 연결하고 무조건 선택으로 보내지 않는다. 기본/강의 범위 응용 문항은 선택 읽기에 의존하지 않는다. 자체 제작 문항은 필수 범위를 정하는 독립 근거가 아니며 부수 지식을 요구하면 문항을 먼저 교체·축소한다.

긴 노트는 본문으로 돌아가는 짧은 복습 길잡이를 둘 수 있다. 규칙·필수 조건·관련 절을 함께 두고 아직 설명하지 않은 새 사실을 요약에서 처음 가르치지 않는다. 복습을 위해 필요한 본문을 없애거나 고정 한 페이지·몇 줄에 맞추지 않는다.

## 충분성과 마무리 판정

노트와 문제집의 제목·본문·표·캡션·문항·해설을 처음부터 끝까지 읽는다. 새 용어·기호가 사용 전에 설명됐는지, 이유와 조건이 연결되는지, 계산/논증의 중간 과정이 재현되는지, 그림·사례와 일반 원리가 연결되는지 본다. 검토자 지식으로 빠진 연결을 메우지 않는다. 부족하면 실제 구절·독자가 막히는 질문·최소 보완을 특정한다. 문항에 없는 도입 이유·사례라도 주요 학습 질문이면 살핀다.

오탈자·비문·반복·빠진 말·용어/기호 불일치·모호한 지시어를 점검한다. ‘위/아래’, 절·문항·페이지 번호는 최종 PDF의 실제 대상과 대조한다. 자동 검색·맞춤법·링크 검사는 후보 탐지이며 전수 읽기의 대체물이 아니다.

충분성·표현 적절성·제안 채택·최종 가독성은 담당 모델이 근거로 판단한다. 페이지/그림/단어/테스트 개수, 소스 이미지 일치율, 원장 칸 채우기를 자동 승인 근거로 쓰지 않는다. 외부 검토는 현재 버전·범위를 확인한 뒤 채택·수정 후 채택·기각한다. 과거 결함과 현재 결함을 구별하며 새 근거 없이 같은 전체 검토를 반복하지 않는다. 실행과 기록은 SKILL.md·로컬 lecture-week가 맡는다.
