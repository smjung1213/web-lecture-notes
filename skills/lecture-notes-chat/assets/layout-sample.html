1. 핵심 문장과 설명

먼저 이해할 관계를 말하고, 뒤에서 이유와 조건을 풀어 설명한다. 같은 단어가 있다는 이유만으로 충분히 설명했다고 보지 않는다. 처음 읽는 사람에게 필요한 과정은 남기고, 이미 전달한 경고나 제작 이력의 반복은 줄인다.

예를 통해 다시 읽기노트 보충 풀이

다섯 상자에 공을 세 개씩 넣으면 전체 공은 5 × 3 = 15개다. ‘15’만 말하는 것보다 상자의 수와 상자당 공의 수를 구분해야 다른 숫자에도 같은 방법을 적용할 수 있다. 이는 디자인을 보여 주기 위한 합성 예시다.

개수와 마지막 번호자료 정정

원자료
합성 예시: ‘0번부터 3번까지 번호가 있으므로 세 개다.’
정정 내용
번호는 0, 1, 2, 3으로 네 개다. 마지막 번호와 전체 개수는 다르다.
근거
나열한 네 번호를 직접 센 결과. 실제 강의 발언이나 외부 자료의 인용이 아니다.

판단 이유 세기를 시작하는 번호와 개수를 구별해야 계산의 한 칸 오류를 피한다.

첨자 견본: 1521310 = 3B6D16, 216 = 65536

분수 견본: 38 = 0.375

2. 중간 과정을 읽는 방법

표 1. 같은 기준을 나란히 비교하는 합성 예시
상자 수상자당 공전체 공
343 × 4 = 12
535 × 3 = 15

코드 1. Python · 합성 예제 · 실행하지 않음

def total_boxes(boxes, per_box):
    return boxes * per_box

total = total_boxes(5, 3)

boxes는 상자의 수, per_box는 상자당 공의 수다. 이 예의 계산 결과는 15다. 계산으로 예상한 값과 프로그램을 실제 실행해서 관찰한 결과는 구별한다.

확인 1. 다른 수에 적용하기정답 보기 ↗

상자가 7개이고 각 상자에 공이 4개씩 있다. 전체 공의 수를 계산하고 두 수의 역할을 설명하라.

풀이

확인 문제 정답과 풀이

확인 1정답문제로 돌아가기 ↩

28개.

풀이 과정

7은 상자의 수, 4는 각 상자에 든 공의 수다. 따라서 7 × 4 = 28개이다. 같은 수를 네 번 더하는 것인지 일곱 번 더하는 것인지 말할 때에는 어떤 양을 반복하는지도 함께 설명한다.

견본의 범위

모든 본문·표·문항은 조판 확인용 합성 자료다. 특정 교수의 발언이나 실제 수업의 내용이 아니다. 외부 시각자료와 강의 원본은 포함하지 않았다.
