수식의 역할을 나누어 읽기

정의와 핵심 식은 다시 찾아볼 수 있게 구분하고, 유도와 계산은 변형의 이유를 문장으로 잇는다.

1.1 정의와 조건합성 p.1 · 9/2

짧은 관계 n > 0 는 문장 안에 둔다. 정의처럼 뒤에서 다시 찾아볼 내용은 본문과 구분하고, 계산은 필요한 설명을 사이에 넣어 연결한다.

정의 1.1 산술평균

관측값 x 1 , … , x n 의 합을 관측 개수 n 으로 나눈 값이다. 평균 x ¯ 는 원래 관측값과 같은 단위를 갖는다.

x ¯ = 1 n ∑ i = 1 n x i ( n > 0 )

시그마의 아래·위 숫자는 더할 항의 범위다. 첫 관측값부터 마지막 관측값까지 한 번씩 더한다. 관측 개수가 0이면 나눗셈을 할 수 없으므로 평균도 정의되지 않는다.

평균을 보고하는 방법에도 규칙이 있다. 평균을 적을 때는 관측 개수 n 을 함께 적고, 개수가 서로 다른 두 평균을 개수 확인 없이 그대로 비교하지 않는다. 이 문장은 형식 견본이며 실제 교수의 발언이 아니다. 실제 노트에서는 교수가 명시적으로 강조하거나 시험 가능성과 연결한 문장에만 쓴다.

1.2 두 합을 짝짓는 이유합성 p.2 · 9/2,4(1)

S n = 1 + 2 + ⋯ + n 을 거꾸로 쓴 합과 더하면, 같은 위치에 있는 두 수의 합은 모두 n + 1 이다. 이런 쌍이 n 개 있으므로 다음과 같이 이어진다.

S n = 1 + 2 + ⋯ + n S n = n + ( n − 1 ) + ⋯ + 1 2 S n = n ( n + 1 )

마지막 줄의 양변을 2로 나누면 공식을 얻는다. 나누는 이유는 같은 합을 두 번 더했기 때문이다.

핵심 공식 1.2

1 + 2 + ⋯ + n = n ( n + 1 ) 2

예를 들어 n = 100 이면 100 ⋅ 101 / 2 = 5050 이다.⁠[1][1]합성 자료 p.2의 n ( n − 1 ) / 2 는 n ( n + 1 ) / 2 의 오기다. 짝짓기는 항의 개수와 각 쌍의 합을 따로 세는 방법이며, 등차수열의 합 전반에 그대로 쓸 수 있다.

1장 정리

  • 1.1평균은 관측값의 합을 개수로 나눈 값이고, 개수가 0이면 정의되지 않는다.
  • 1.1평균을 적을 때는 관측 개수를 함께 적는다.
  • 1.21부터 n 까지의 합은 앞뒤를 짝지으면 각 쌍의 합이 n + 1 로 같다는 데서 나온다.

정답과 단계별 해설

결과가 다를 때는 마지막 답만 비교하지 말고, 처음 달라지는 값이나 쌍의 개수를 찾는다.

해설 1. 평균은 모든 값을 반영한다문제로

정답평균 6 → 16. 변화량 30을 개수 3으로 나눈 만큼 증가한다.

합은 3 + 5 + 10 = 18 이고 개수는 3이므로 평균은 18 / 3 = 6 이다. 10을 40으로 바꾸면 합이 30 늘어 48이 되므로 평균은 48 / 3 = 16 이다. 평균은 증가량 30을 개수 3으로 나눈 10만큼 커졌다.

해설 2. 쌍의 합과 쌍의 개수를 따로 센다문제로

정답자연수 합 5050, 짝수 합 2550. 두 줄의 쌍은 각각 100개, 50개다.

합을 거꾸로 쓴 합과 더하면 각 쌍의 합은 101이고 쌍은 100개다.

2 S = 100 ⋅ 101 ⇒ S = 5050.

짝수의 합은 항이 50개이고 각 쌍의 합은 2 + 100 = 102 이다.

2 T = 50 ⋅ 102 ⇒ T = 2550.

두 계산은 방법이 같지만 항의 개수가 100개와 50개로 다르다. 개수를 마지막 항의 값(100)으로 착각하면 짝수 합을 두 배로 잘못 구한다.
