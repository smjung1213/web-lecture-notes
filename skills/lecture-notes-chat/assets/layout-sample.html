정보 표현과 읽기 순서

아래 수치·그림·인용문은 조판 검사용으로 새로 만든 예시다. 실제 강의자료에서 가져온 내용이 아니다.

1. 수식의 역할을 나누어 읽기

짧은 관계 n > 0 는 문장 안에 둔다. 정의나 다시 찾아볼 핵심 식은 본문과 구분하고, 유도와 계산은 필요한 설명을 사이에 연결한다.

정의 — 산술평균

관측값 x 1 , … , x n 의 합을 관측 개수 n 으로 나눈 값이다. x ¯ 는 평균을 나타내며 원래 관측값과 같은 단위를 갖는다.

x ¯ = 1 n ∑ i = 1 n x i ( n > 0 )

시그마의 아래·위 숫자는 더할 항의 범위다. 따라서 첫 관측값부터 마지막 관측값까지 한 번씩 더한다. 개수가 0이면 이 정의의 나눗셈을 적용할 수 없다.

유도 — 두 합을 짝짓는 이유

S n = 1 + 2 + ⋯ + n 을 거꾸로 쓴 합과 더하면, 같은 위치의 두 수는 모두 n + 1 이다. 이런 쌍이 n 개 있으므로 다음과 같이 연결된다.

S n = 1 + 2 + ⋯ + n S n = n + ( n − 1 ) + ⋯ + 1 2 S n = n ( n + 1 ) → divide by  2 S n = n ( n + 1 ) 2

화살표의 ‘2로 나눔’은 변형의 이유이므로 재조판에서도 남긴다. 긴 한국어 설명은 수식 내부 대신 바로 앞뒤 문장에 둔다.

계산과 조건을 가진 식

합성 관측값이 2, 4, 6이면 x ¯ = 2 + 4 + 6 3 = 4 이다. 계산 결과만 아니라 대입한 값과 개수를 함께 보여 준다.

| x | = { x , x ≥ 0 , − x , x < 0. A = [ 1 2 3 4 ]

왼쪽은 조건에 따라 표현이 달라지는 식, 오른쪽은 행과 열의 위치가 의미를 갖는 행렬이다. 둘 다 편집 HTML의 LaTeX 원문에서 생성한다.

2. 표·그림·설명 사이의 경계

표는 값을 비교하고, 그림은 단계의 연결을 보여 준다. 원자료의 모양 자체가 학습 대상이 아니라면 같은 정보를 읽기 좋은 표나 수식으로 옮길 수 있다.

표 1. 합성 기록을 재작성한 측정표
단계시간 (분)처리량 (개)조건
준비20측정 장치를 안정화한다.
측정 A312같은 간격으로 측정한다.
측정 B520A와 같은 기준을 사용한다.

조건: 시간은 단계별 소요 시간이다. 준비 단계는 처리율 비교에서 제외한다. 출처: 이 견본의 합성 기록. 세 행·네 열·값·단위와 이 조건을 함께 보존했다.

그림을 읽은 뒤 설명으로 이어진다

관찰한 것을 먼저 기록하고, 같은 조건에서 얻은 값인지 확인한 뒤 해석한다. 이 순서가 바뀌면 수치 차이가 조건 차이 때문인지 판단하기 어렵다.

세로로 긴 그림은 여기처럼 본문 왼쪽에 놓을 수 있다. 폭은 비율만으로 결정하지 않고 가장 작은 필수 라벨을 읽을 수 있는지 확인한다. 긴 설명이나 복잡한 라벨에는 본문 전체 폭 또는 다음 문단 배치가 낫다.

인용과 논증에는 다른 구분을 쓴다

“기록의 양이 늘어도 서로 다른 조건을 섞으면 비교는 더 어려워진다.”

출처: 이 견본에서 작성한 합성 인용문. 실제 인물의 발언이 아니다.

이 문장은 비교할 때 조건을 맞추어야 한다는 주장을 뒷받침한다. 그러나 기록을 적게 남겨도 된다는 결론까지 뒷받침하지는 않는다. 인용문과 필자의 해석은 서로 구분해서 읽는다.

정정. 합성 초안의 “준비를 포함한 처리 시간은 8분”은 “측정 시간은 8분이며, 준비를 포함하면 10분”으로 바로잡는다. 표 1의 시간 열을 더하면 차이를 확인할 수 있다.

이 견본에서는 출처는 표·그림·인용문 가까이에, 정정은 올바른 설명 뒤에 두었다. 일반 본문에 반복 태그나 박스를 붙이지 않았다.
