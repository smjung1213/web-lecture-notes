수식과 그림

이 문장은 합성 시험을 위해 수업 강조 모양을 보여 준다. 긴 문장이 두 줄 이상으로 이어져도 빨간 물결이 각 줄의 글자나 다음 줄과 닿지 않는지 확인한다.

문장 속 수식 의 크기와 기준선을 확인한다. 정정 표시는 같은 쪽의 설명으로 연결한다.⁠[1][1]정정 검사 문장 하나. 이 문장은 호출 표시와 같은 페이지 하단에 있어야 한다.

페이지 하단 정정

2.1 코드와 출력합성 입력

코드 글꼴은 고정폭 고딕이다. 두 번째 정정은 문서 전체 연속 번호를 유지한다.⁠[2][2]정정 검사 문장 둘. 앞 장의 번호에 이어 [2]로 표시하고 같은 쪽 하단에 둔다.

total = 2 + 3
print(total)
