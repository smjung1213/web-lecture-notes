# Codex 검토 요청

첨부한 [과목] [주차] 노트·문제집을 지정 원자료와 함께 검토하고 필요한 수정·최종 PDF 확인·허용된 저장까지 진행해줘. 현재 지정 독자·범위·제한이 기존 지침과 리뷰보다 우선해. 원자료·받은 산출물·기존 공식본은 보존하고 새 사본에서 수정해줘.

로컬 lecture-week에 따라 원자료·범위·원고 버전을 고정한 뒤 Astra Medium과 Claude Opus 5 High가 같은 원고를 병렬로 독립 검토해줘. Claude는 지정 원자료와 노트·문제집 전체의 정확성·설명 충분성·전개 흐름을 확인하고 다른 검토 모델 fallback·하위 에이전트 재위임은 하지 마. 중간 지적을 서로 전달하지 말고 두 최종 결과를 모은 뒤 Astra가 수정해줘.

원본 파일 보존과 PDF 표현을 구별해줘. 수식 재조판·표 재작성·의미 있는 통합은 coverage의 처리/상태·원자료/최종 위치·필요한 값·조건·관계·유도에 대조하고, 이미지 미수록이나 표현 변경만으로 누락으로 되돌리지 마. 같은 숫자 몇 개가 있다는 이유만으로 충분하다고 하지도 마. 새 수식은 MathJax LaTeX와 실제 PDF까지 확인해줘.

내용 판정·수정 후 Gemini 3.8 Flash High가 큰 파트 몇 개씩 새 세션에서 두 문서 전체를 빠짐없이 작문 검토하게 해줘. 인접 문맥·목차·용어 기준을 함께 주고 Astra가 제안의 의미 보존과 분할 경계 연결을 판정해줘. 외부 중간 사고·진행 대화·원시 도구 응답·부분 답변은 일반 코드가 비공개 처리하고 완료 후 최종 결과·범위·모델·오류 상태만 받아줘. 정규 상세 토큰·비용 집계는 생략해줘.

기계 도우미는 자료 준비·분할·범위·인용·변경·재생성 검사에 사용하고 의미·충분성·최종 가독성을 자동 승인하지 마. 기본 외부 검토가 막히면 해당 단계는 미완료로 남기고 다른 모델로 대체하지 말아줘. 가능한 독립 작업은 계속해줘. “검토만/수정하지 마/저장하지 마” 등 현재 제한이 있으면 그대로 지키고, 이미 허용된 통상적인 수정·적용을 선택마다 재승인받지 마.
