# Codex 검토 요청

첨부한 [과목] [주차] 노트를 검토해줘. 현재 사용자 지정 독자·범위와 보존 요구가 기존 지침·리뷰의 충분/제외 판정보다 우선해. 원자료와 편집본을 대조하고 필요한 수정·계산·PDF 확인까지 진행해줘. Astra Medium을 기본으로 하되 내가 지정한 모델·추론 수준을 유지해줘. 실행 분담은 로컬 lecture-week에 따라 실제 사용 조건이 검증된 검증기를 조건부로 사용하고 Codex가 최종 결과·근거를 판정해줘. 사용 가능한 검증기가 없으면 직접 검토하고 외부 검토 미실시를 밝혀줘. 실제 접근·실행한 범위와 미확인을 구별해줘. “검토만”, “저장하지 마” 등 이번 명시 제한이 있으면 그대로 지켜줘.
